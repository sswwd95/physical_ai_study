# 기초 SPC 공식 모음

## 3시그마 관리한계
- 중심선: `CL = 평균`
- 상한: `UCL = 평균 + 3 × 표준편차`
- 하한: `LCL = 평균 - 3 × 표준편차`

## 이동범위 관리도
- 이동범위: `MR_i = |X_i - X_(i-1)|`
- n=2 이동범위의 상한: `UCL_MR = 3.267 × MR평균`

## X-bar 관리도
소그룹 크기 n=5일 때:
- `UCL = X이중평균 + 0.577 × R평균`
- `LCL = X이중평균 - 0.577 × R평균`

## R 관리도
소그룹 크기 n=5일 때:
- `UCL = 2.114 × R평균`
- `LCL = 0 × R평균`

## 공정능력
- `Cp = (USL - LSL) / (6σ)`
- `CPU = (USL - μ) / (3σ)`
- `CPL = (μ - LSL) / (3σ)`
- `Cpk = min(CPU, CPL)`

## 주의
관리도 상수는 소그룹 크기에 따라 달라집니다. 실제 품질 시스템에서는
승인된 SPC 표준과 공정 엔지니어의 기준을 사용해야 합니다.
