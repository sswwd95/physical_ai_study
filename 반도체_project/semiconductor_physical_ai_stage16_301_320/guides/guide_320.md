# 실습 320 — automated_digital_twin_report

## 1. 학습 목표
자동 디지털 트윈 Excel 보고서를 생성합니다.

## 2. Antigravity용 예제 소스 생성 하네스 프롬프트
```text

```

## 3. 실행 명령
```bat
conda activate semi-physical-ai-stage16
python examples\ex320_automated_digital_twin_report.py
```

요청한 디지털 트윈·센서 융합 결과가 출력 또는 저장됩니다.
