# CUSUM·EWMA 핵심 공식

## 표준화 잔차
`z_t = (x_t - μ_0) / σ_0`

## 상방 CUSUM
`C_t^+ = max(0, C_(t-1)^+ + z_t - k)`

## 하방 CUSUM
`C_t^- = min(0, C_(t-1)^- + z_t + k)`

경보 조건:
- `C_t^+ >= h`
- `|C_t^-| >= h`

## EWMA
`Z_t = λX_t + (1-λ)Z_(t-1)`

## EWMA 표준편차
`σ_Zt = σ * sqrt( λ/(2-λ) * (1-(1-λ)^(2t)) )`

## EWMA 관리한계
- `UCL_t = μ_0 + Lσ_Zt`
- `LCL_t = μ_0 - Lσ_Zt`

## 파라미터 해석
- 작은 k: 작은 변화에 민감
- 작은 h: 빠른 경보, 높은 오경보 가능성
- 큰 lambda: 최근 변화에 빠르게 반응
- 작은 lambda: 더 부드럽지만 반응이 느림
