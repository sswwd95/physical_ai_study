# 수율 회귀 핵심 개념

## 평가 지표
- MAE: 평균적으로 몇 %p 틀리는지 이해하기 쉬움
- RMSE: 큰 오차에 더 큰 벌점을 부여
- R²: 목표값 변동 중 모델이 설명한 비율

## 정규화 회귀
- Ridge: 모든 계수를 줄여 안정화
- Lasso: 일부 계수를 0으로 만들어 특징 선택
- Elastic Net: Ridge와 Lasso의 특성을 결합

## 잔차
- residual = actual - prediction
- 양수 잔차: 실제 수율이 예측보다 높음
- 음수 잔차: 실제 수율이 예측보다 낮음
- 저수율 구간에서 큰 음수 잔차는 특히 위험할 수 있음

## 예측구간
- 하나의 점 예측만으로는 불확실성을 알기 어려움
- 여러 모델 또는 부트스트랩 예측 분포로 구간을 근사 가능
