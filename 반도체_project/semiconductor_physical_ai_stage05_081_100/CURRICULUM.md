# 5단계 교수·학습 운영안

## 권장 시간
총 18~24시간

- 이상 유형과 데이터 프로파일: 2시간
- MAD·IQR·문맥·이동잔차: 4시간
- Isolation Forest: 4시간
- LOF와 One-Class SVM: 4시간
- Robust Covariance와 PCA 오차: 3시간
- 모델 평가와 임계값 최적화: 3시간
- 앙상블·대시보드·보고서: 2~4시간

## 학습 완료 기준
- 점 이상·집단 이상·문맥적 이상을 구분할 수 있다.
- 비지도 탐지 모델의 주요 파라미터를 설명할 수 있다.
- precision, recall, specificity, F1을 계산할 수 있다.
- 연속형 점수에서 임계값을 비교할 수 있다.
- 여러 모델의 투표 기반 앙상블을 구현할 수 있다.
- LOT별 이상률과 모델 성능 보고서를 생성할 수 있다.
