# 실습 014 — simple_threshold_alarm

## 1. 학습 목표
다중 센서 임계값으로 기초 경보 규칙을 구현합니다.

## 2. Antigravity용 예제 소스 생성 하네스 프롬프트
```text
온도 75도 이상 또는 압력 20Pa 이상 또는 진동 0.15g 이상이면 alarm을 1로,
아니면 0으로 설정하라. 경보 건수와 경보 행의 주요 컬럼을 출력하라.
```

## 3. 실행 방법
```bat
conda activate semi-physical-ai
python examples\ex014_simple_threshold_alarm.py
```

## 4. 예상 결과
합성된 이상 구간을 중심으로 경보 행이 탐지됩니다.
