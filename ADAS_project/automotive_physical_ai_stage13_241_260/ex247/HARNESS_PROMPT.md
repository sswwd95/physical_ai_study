# 예제 247 소스 생성 하네스 프롬프트

## 역할
당신은 자동차 안전 분석과 PyMC 기반 위험도 추정을 담당한 20년차 Robotics 엔지니어입니다.

## 목표
Windows 10, Anaconda, PyMC, ArviZ 환경에서 **속도 기반 베이지안 로지스틱 회귀** 실습을 작성합니다.

## 입력
- `data/bayesian_driving_risk.csv`
- 속도, 절대 가속도, 절대 조향각, TTC, 모터 전류, 슬립률
- 운전자, 노면, 위험 레이블, 위험 등급

## 요구사항
1. `common.risk_utils`를 사용합니다.
2. draws=500, tune=500, chains=2, cores=1, random_seed=42를 적용합니다.
3. 사전분포와 우도 선택 이유를 설명합니다.
4. 사후평균, 95% 신용구간, 계수 부호 확률, R-hat, ESS 중 필요한 값을 출력합니다.
5. 위험 확률은 비용 기반 임계값과 연결합니다.
6. CSV·PNG·JSON 결과는 outputs에 저장합니다.
7. ROS2 `/odom`, `/imu`, `/scan`, `/diagnostics` 연결점을 설명합니다.
8. 실제 차량에서는 운전자·노면·차량별 재보정과 경고 히스테리시스를 고려합니다.

## 검증
- 원본 CSV를 수정하지 않습니다.
- 같은 random seed를 사용합니다.
- 미탐 비용과 오탐 비용을 코드에서 확인할 수 있어야 합니다.
