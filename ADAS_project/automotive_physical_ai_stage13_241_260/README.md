# 자동차 Physical AI 하네스 엔지니어링
## 13단계 | 241~260제 | PyMC 기반 이상 주행 확률·위험도 추정

### 주요 내용
- 전체 이상 주행 확률
- 베타-베르누이 모델
- 위험률 95% 신용구간
- 기준 초과 사후확률
- 속도·TTC·다중 특징 베이지안 로지스틱 회귀
- 계수 부호 사후확률
- 노면별·운전자별 위험도
- 운전자 계층 모델
- 노면·운전자 교차 효과
- 사후 예측 위험확률
- 미탐·오탐 비용 기반 임계값
- R-hat·ESS 진단
- 통합 위험도 리포트

총 420개 합성 주행 샘플입니다.
