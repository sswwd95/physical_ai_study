## 실무 연결
이 예제는 ROS2 토픽 또는 MuJoCo 센서 배열을 받기 전에 Python 자료구조와 데이터 처리 흐름을 연습하는 단계입니다. 실제 차량 프로젝트에서는 단위, 시간축, 임계값, 결측값을 항상 함께 확인해야 합니다.

## 라인별 해설
- **01행** `import numpy as np` — 필요한 라이브러리 또는 공통 함수를 불러옵니다.
- **03행** `speed_mps = np.array([4.2, 5.1, 5.8, 6.4])` — 센서 값, 조건식 또는 계산 결과를 변수에 저장합니다.
- **04행** `calibration_offset = -0.15` — 센서 값, 조건식 또는 계산 결과를 변수에 저장합니다.
- **05행** `corrected = speed_mps + calibration_offset` — 센서 값, 조건식 또는 계산 결과를 변수에 저장합니다.
- **06행** `speed_kph = corrected * 3.6` — 센서 값, 조건식 또는 계산 결과를 변수에 저장합니다.
- **08행** `print("보정 속도(m/s):", np.round(corrected, 2))` — 계산 결과나 상태를 화면에 출력해 확인합니다.
- **09행** `print("변환 속도(km/h):", np.round(speed_kph, 2))` — 계산 결과나 상태를 화면에 출력해 확인합니다.
