# 예제 310 소스 생성 하네스 프롬프트

## 역할
당신은 MuJoCo와 ROS2 기반 모바일 로봇·자동차 제어를 담당한 20년차 Robotics 엔지니어입니다.

## 목표
Windows 10, Anaconda, MuJoCo 3.6.0 환경에서 **계단 목표속도 추종** 실습을 작성합니다.

## 요구사항
1. `common.control_utils`의 PID·운동학·시뮬레이션 함수를 사용합니다.
2. 제어 주기와 모든 단위를 변수명에 표시합니다.
3. P·PI·PID, 출력 포화, 데드존, 안티와인드업을 구분합니다.
4. 결과 CSV·PNG·JSON은 `outputs`에 저장합니다.
5. 제어 성능은 MAE·RMSE·최종오차 중 필요한 지표로 평가합니다.
6. 바퀴 제어 입력은 액추에이터 허용범위를 넘지 않도록 제한합니다.
7. ROS2 `/cmd_vel`, `/odom`, `/joint_states`와 연결점을 설명합니다.
8. 실제 차량에서는 actuator delay, wheel slip, saturation, fail-safe를 추가 고려합니다.

## 검증 기준
- 같은 입력과 게인에서 같은 결과가 재현되어야 합니다.
- PID 게인과 제한값을 코드에서 확인할 수 있어야 합니다.
- 안전 정지와 포화 처리를 생략하지 않습니다.
