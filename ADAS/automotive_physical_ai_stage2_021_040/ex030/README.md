## 실무 연결
이 예제는 ROS2 토픽 또는 MuJoCo 센서 배열을 받기 전에 Python 자료구조와 데이터 처리 흐름을 연습하는 단계입니다. 실제 차량 프로젝트에서는 단위, 시간축, 임계값, 결측값을 항상 함께 확인해야 합니다.

## 라인별 해설
- **01행** `import numpy as np` — 필요한 라이브러리 또는 공통 함수를 불러옵니다.
- **03행** `distance = np.array([8.0, 5.5, 3.2, 2.8, 1.9, 4.1])` — 센서 값, 조건식 또는 계산 결과를 변수에 저장합니다.
- **04행** `mask = distance < 3.0` — 센서 값, 조건식 또는 계산 결과를 변수에 저장합니다.
- **06행** `print("위험 마스크:", mask)` — 계산 결과나 상태를 화면에 출력해 확인합니다.
- **07행** `print("위험 거리:", distance[mask])` — 계산 결과나 상태를 화면에 출력해 확인합니다.
- **08행** `print("위험 샘플 수:", int(mask.sum()))` — 계산 결과나 상태를 화면에 출력해 확인합니다.
