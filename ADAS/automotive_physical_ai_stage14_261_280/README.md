# 자동차 Physical AI 하네스 엔지니어링
## 14단계 | 261~280제 | 차량 부품 상태·예지보전 기초

### 주요 내용
- 모터 온도·전류 열화 추세
- 베어링 진동 RMS
- 배터리 전압 강하·내부저항 증가
- 휠 마찰 이상
- 부품별 임계값 경고
- 건강도 점수
- 열화 시작점
- 회귀 기반 상태 예측
- 고장 분류
- 특징 중요도
- 단순 잔여수명 추정
- 유지보수 우선순위
- 상태 대시보드
- 통합 예지보전 리포트

### 데이터
1,250초, 0.5초 주기, 총 2,500행의 합성 차량 부품 상태 로그입니다.
850초 이후 열화가 가속되는 시나리오를 포함합니다.

### 설치
```bat
conda env create -f environment.yml
conda activate auto_physical_ai
```
