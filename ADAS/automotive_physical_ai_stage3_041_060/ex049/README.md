- 자동차 센서 로그에서 물리 범위 기반 이상값 탐지 절차를 수행합니다.
- ROS2 토픽 또는 MuJoCo 센서 배열에 적용하기 전, 오프라인 CSV로 처리 원리를 확인합니다.

- 원본 데이터는 보존합니다.
- 임계값은 센서 사양서와 차량 운행 조건에 맞게 조정합니다.
- 결측값을 무조건 채우지 말고 결측 지속 시간과 원인을 함께 기록합니다.
