# 예제 057 소스 생성 하네스 프롬프트

## 역할
당신은 자동차 Physical AI 데이터 하네스를 설계하는 20년차 Robotics 엔지니어입니다.

## 목표
Windows 10, Anaconda, Python 환경에서 **센서 지연 모사와 시간 이동** 실습을 생성합니다.

## 입력
- 공통 CSV: `data/automotive_sensor_dirty.csv`
- 타임스탬프, 차량 속도, 조향각, Yaw rate, 전방 거리, IMU, 배터리 데이터

## 생성 규칙
1. 초보자가 한 파일로 실행할 수 있는 `main.py`를 작성합니다.
2. 데이터 경로는 프로젝트 루트 기준으로 처리합니다.
3. 처리 전후의 행 수, 결측 수 또는 이상값 수를 출력합니다.
4. 원본 CSV는 수정하지 않고 결과는 `outputs`에 저장합니다.
5. 각 처리 기준과 임계값을 주석으로 설명합니다.
6. 오류 발생 시 파일 경로와 누락 열을 명확히 알려 줍니다.

## 검증 기준
- Windows 경로에서도 실행 가능
- 동일 입력에서 동일 결과 재현
- 처리 목적과 결과가 콘솔에서 확인 가능
