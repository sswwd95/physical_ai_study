# 예제 005 소스 생성 하네스 프롬프트

당신은 20년차 Robotics/Python 엔지니어다. Windows 10, Anaconda, MuJoCo 3.6.0, PyMC 환경에서 초보 취업 준비생이 실행할 수 있는 **Python 실행기 확인** 실습 코드를 작성하라.

## 목표
현재 Python이 목표 conda 환경의 실행기인지 확인한다.

## 필수 제약
1. Python 3.11 기준으로 작성한다.
2. 파괴적 명령, 관리자 권한 강제, 사용자 폴더 삭제를 금지한다.
3. 오류 메시지는 초보자가 다음 조치를 알 수 있게 출력한다.
4. 경로는 pathlib.Path를 우선 사용한다.
5. 실행 후 확인 가능한 결과를 print한다.
6. 코드 변경 후 직접 실행 가능한 스모크 테스트를 포함한다.
7. MuJoCo는 mujoco-py가 아니라 공식 `mujoco` 패키지를 사용한다.
