# 설계 참고

센서 모델 구성:
- 가속도계: 기준 가속도 + 고정 바이어스 + 선형 드리프트 + 백색 잡음
- 자이로: 기준 각속도 + 고정 바이어스 + 랜덤 워크 + 백색 잡음
- 엔코더: 회전각을 정수 틱으로 양자화한 뒤 속도로 환산
- 슬립: 특정 구간에서 엔코더 속도를 실제 속도보다 크게 모사

ROS2 연결 대상:
- `sensor_msgs/Imu`
- `sensor_msgs/JointState`
- `nav_msgs/Odometry`

실차 캘리브레이션에서는 정지 구간 자동 검출, 온도별 바이어스 맵, 센서 축 정렬,
하드웨어 타임스탬프와 공분산 추정이 추가로 필요합니다.
