# 자동차 Physical AI 하네스 엔지니어링
## 8단계 | 141~160제 | 자동차 IMU·엔코더 센서 모델링과 노이즈 분석

### 주요 내용
- IMU 데이터 구조와 측정 오차
- 가속도·자이로 바이어스
- 이동평균 노이즈 완화
- 오차 분포와 드리프트 시각화
- 자이로 적분 자세 오차
- 엔코더 틱과 분해능
- 속도 양자화 오차
- 누적 거리 오차
- 휠 슬립 탐지
- 구간별 노이즈 통계
- 랜덤 워크
- 캘리브레이션 계수 적용
- 통합 품질 분석

### 설치
```bat
conda env create -f environment.yml
conda activate auto_physical_ai
```

### 전체 실행
```bat
00_run_all_examples.bat
```

### 데이터 특성
120초, 100Hz 합성 로그를 사용합니다.
가속도 바이어스·드리프트·가우시안 노이즈, 자이로 바이어스·랜덤 워크,
엔코더 양자화와 55~65초 휠 슬립 구간을 포함합니다.
