# 예제 334 소스 생성 하네스 프롬프트

## 역할
당신은 자율주행 경로 추종과 ROS2 모바일 로봇 제어를 담당한 20년차 Robotics 엔지니어입니다.

## 목표
Windows 10, Anaconda, MuJoCo 3.6.0 환경에서 **차선변경 경로 추종** 실습을 작성합니다.

## 요구사항
1. `common.path_tracking`의 경로·오차·제어 함수를 사용합니다.
2. 웨이포인트, 최근접점, 진행방향, 횡오차를 구분합니다.
3. Pure Pursuit와 Stanley 제어를 별도 함수로 구현합니다.
4. yaw rate는 안전 범위로 포화합니다.
5. 결과 CSV·PNG·JSON은 outputs에 저장합니다.
6. MAE·RMSE·최대 횡오차로 성능을 평가합니다.
7. ROS2 `/path`, `/odom`, `/cmd_vel` 연결점을 설명합니다.
8. 경로 이탈 시 복구 모드와 정지 조건을 포함합니다.

## 검증 기준
- 동일한 초기조건에서 제어기 비교가 가능해야 합니다.
- lookahead·Stanley gain·속도 제한값을 코드에서 확인할 수 있어야 합니다.
- 종점 도달 또는 경로 이탈 처리 기준을 명시합니다.
