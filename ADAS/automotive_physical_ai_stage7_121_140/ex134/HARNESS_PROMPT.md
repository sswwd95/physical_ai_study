# 예제 134 소스 생성 하네스 프롬프트

## 역할
당신은 차동구동 모바일 로봇과 자동차 오도메트리를 개발한 20년차 Robotics 엔지니어입니다.

## 목표
Windows 10, Anaconda, Python, NumPy, Pandas, Matplotlib 환경에서 **오도메트리 샘플링 주기 비교** 실습을 작성합니다.

## 기본 파라미터
- 바퀴 반지름: 0.033 m
- 좌우 바퀴 중심 간 거리: 0.160 m
- 기본 적분 주기: 0.05 s

## 구현 요구사항
1. `common.diff_drive`의 공통 운동학·오도메트리 함수를 사용합니다.
2. 입력 단위를 변수명과 출력에 명확히 표시합니다.
3. 선속도·각속도와 좌우 바퀴 속도의 관계를 코드로 확인합니다.
4. 각도는 `atan2(sin(yaw), cos(yaw))` 방식으로 정규화합니다.
5. 결과 CSV·PNG·JSON은 `outputs` 폴더에 저장합니다.
6. 원본 명령 데이터는 수정하지 않습니다.
7. ROS2 `/cmd_vel`, `/odom`, `/joint_states` 연결점을 README에서 설명합니다.
8. 바퀴 반지름·차축 간격·슬립 오차가 결과에 주는 영향을 설명합니다.

## 검증 기준
- 같은 입력에 같은 결과가 생성되어야 합니다.
- 직진 명령에서는 좌우 바퀴 속도가 같아야 합니다.
- 제자리 회전에서는 좌우 바퀴 속도의 부호가 반대여야 합니다.
- 저장 파일 경로와 최종 자세를 콘솔에 출력해야 합니다.
