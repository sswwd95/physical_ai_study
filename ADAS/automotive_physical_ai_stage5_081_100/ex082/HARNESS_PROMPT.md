# 예제 082 하네스 프롬프트

당신은 20년차 자동차 Robotics 엔지니어입니다. Windows 10, Anaconda, NumPy, Pandas, Matplotlib 환경에서 **타임스탬프 정렬과 중복 검사** 예제를 작성하십시오.

요구사항:
1. `common.sync_utils`의 데이터 로더와 출력 경로 함수를 사용합니다.
2. 서로 다른 센서 주기와 타임스탬프 오차를 코드에서 명확히 다룹니다.
3. 원본 CSV는 변경하지 않고 결과를 `outputs`에 저장합니다.
4. 임계값, 허용 오차, 가중치의 의미를 주석으로 설명합니다.
5. 초보자가 이해할 수 있도록 입력·처리·출력 순서로 작성합니다.
6. 실차 적용 시 필요한 추가 고려사항을 README에 기록합니다.
