# 초보자용 주석 읽는 방법

이 프로젝트의 예제 1~100 Python 파일에는 코드 바로 위에 한국어 설명 주석을 추가했습니다.

## 추천 학습 순서

1. 예제 파일 맨 위의 목적을 읽습니다.
2. `#`으로 시작하는 설명을 먼저 읽습니다.
3. 바로 아래 한 줄 또는 코드 묶음이 실제로 어떤 일을 하는지 확인합니다.
4. 코드를 실행하고 이미지 창이나 터미널 출력을 확인합니다.
5. 숫자나 경로를 조금씩 바꾸어 결과 차이를 관찰합니다.

## 주의 사항

- `practice_images/sample.jpg` 같은 상대 경로를 사용하므로 반드시 프로젝트 루트인 `opencv_100` 폴더에서 실행하세요.
- 웹캠 예제는 카메라 권한이 필요합니다.
- ROS2 예제 81~100 중 일부는 Windows의 일반 Anaconda 환경만으로 실행되지 않으며 ROS2 Humble과 `cv_bridge`가 필요합니다.
- 이미지 창이 멈춘 것처럼 보여도 창을 선택하고 키를 누르면 종료되는 예제가 많습니다.
