# 반도체 Physical AI 최종 프로젝트 가이드

## 프로젝트 질문
1. 어떤 공정 문제를 해결하는가?
2. 어떤 데이터가 필요한가?
3. 어떤 품질·안전 기준을 만족해야 하는가?
4. 모델 성능이 운영 행동으로 어떻게 연결되는가?
5. 실패 시 어떻게 안전하게 복구하는가?

## 최종 산출물
- 요구사항 추적표
- 데이터 계약
- 품질 검증 결과
- 수율·고장·RUL 모델
- 통합 예측과 행동 추천
- 안전 우선 게이트
- KPI·오차분석
- 최종 Excel 보고서
- 포트폴리오 사례
- 발표 1페이지 요약
- 배포 체크리스트

## 발표 구조
문제 → 데이터 → 접근 → 모델 → 성능 → 안전 → 운영 → 한계 → 다음 단계
