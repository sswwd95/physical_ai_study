# 다중 클래스 분류와 튜닝 핵심 개념

## 평균 방식
- Macro: 클래스별 지표를 동일 가중치로 평균
- Weighted: 클래스 support를 가중치로 평균
- Micro: 전체 TP·FP·FN을 합쳐 계산

## 모델 튜닝
- GridSearchCV: 정의한 모든 조합을 탐색
- RandomizedSearchCV: 일부 조합을 무작위 탐색
- 튜닝 지표는 문제 목적에 맞게 선택
- 희소 불량 유형이 중요하면 accuracy보다 f1_macro가 유리

## 예측확률 운영
- 최대 확률이 낮으면 자동 판정 보류
- 상위 두 클래스 확률 차이가 작으면 재검사
- 확률 보정은 예측확률과 실제 빈도의 일치를 개선
