# 반도체 센서 데이터 품질검사 체크리스트

## 입력 계약
- [ ] 파일 경로와 파일명이 명확하다.
- [ ] 필수 컬럼 목록이 정의되어 있다.
- [ ] 각 센서 단위가 문서화되어 있다.
- [ ] timestamp 시간대와 정밀도가 정의되어 있다.
- [ ] LOT, 장비, 챔버, 레시피 식별자가 있다.

## 데이터 품질
- [ ] 자료형 변환 실패 건수를 확인했다.
- [ ] 결측 개수와 비율을 확인했다.
- [ ] 완전 중복과 복합키 중복을 구분했다.
- [ ] 시간축 역순과 샘플링 간격을 검사했다.
- [ ] 허용 범위를 공정 엔지니어가 검토했다.
- [ ] 범주형 허용값을 검증했다.
- [ ] 센서 간 교차 규칙을 검토했다.

## 변경 통제
- [ ] 원본을 수정하지 않았다.
- [ ] 제거·보간·보정 건수를 기록했다.
- [ ] 정제 코드 버전을 기록했다.
- [ ] 출력 데이터와 감사 로그를 함께 저장했다.
