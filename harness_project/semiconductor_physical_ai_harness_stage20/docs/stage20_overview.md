# 20단계 개요: 불균형 데이터와 001~100 통합 미니 프로젝트

| 실습 | 주제 | 주요 출력 |
|---:|---|---|
|096|클래스 불균형 진단|CSV·JSON|
|097|Under·Over Sampling|균형 학습 CSV|
|098|SMOTE 유사 합성|합성 학습 CSV|

## 실무 핵심
불균형 데이터에서는 Accuracy만으로 모델을 선택하면 안 됩니다. 불량 미탐과 오경보 비용을 정의하고, 샘플링·클래스 가중치·임계값 조정을 함께 비교해야 합니다.
