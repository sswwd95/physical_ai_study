# 실습 031~035 라인별 해설

## 실습 031 센서 단위 계약 검증
1. 단위 계약은 같은 센서명이 서로 다른 단위로 들어오는 문제를 방지합니다.
2. 기대 단위와 허용 입력 단위를 설정 파일로 관리합니다.
3. 입력 열 존재 여부와 단위 허용 여부를 분리해 검사합니다.
4. 두 조건이 모두 참일 때만 검증 통과로 처리합니다.
5. 단위 오류를 방치하면 이상 탐지와 예측 모델이 모두 왜곡됩니다.
6. 검증 실패 시 변환이나 분석을 진행하지 않는 것이 안전합니다.

## 실습 032 센서 단위 변환
1. 화씨를 섭씨로 바꾸려면 32를 뺀 뒤 5/9를 곱합니다.
2. Pa를 kPa로 바꾸려면 1000으로 나눕니다.
3. slm을 sccm으로 바꾸려면 1000을 곱합니다.
4. m/s를 mm/s로 바꾸려면 1000을 곱합니다.
5. mA를 A로 바꾸려면 1000으로 나눕니다.
6. 변환 후 물리 범위를 검사해 잘못된 변환식을 조기에 발견합니다.

## 실습 033 시간 간격 이상 탐지
1. 시간순으로 정렬하지 않으면 간격 계산이 의미가 없습니다.
2. `diff()`는 현재 시각과 이전 시각의 차이를 구합니다.
3. 간격 0초는 중복 시각입니다.
4. 기대 간격보다 긴 구간은 누락 샘플 가능성을 나타냅니다.
5. 간격에서 기대 간격을 빼면 누락 개수를 근사할 수 있습니다.
6. 실제 스트리밍에서는 네트워크 지연과 버퍼링도 함께 확인해야 합니다.

## 실습 034 중복 시각 처리
1. `duplicated(..., keep=False)`는 중복 그룹의 모든 행을 찾습니다.
2. 원본 중복 행을 별도 파일로 보존해야 추적성이 유지됩니다.
3. 센서값 평균은 교육용 통합 규칙입니다.
4. Lot과 Recipe는 같은 시각에서 일치한다고 가정하고 첫 값을 사용합니다.
5. 처리 후 timestamp 중복 개수를 다시 검사합니다.
6. 실제 장비에서는 데이터 출처 우선순위나 수집 시스템 ID를 사용할 수 있습니다.

## 실습 035 센서 드리프트 기초 탐지
1. 최근 구간만 사용하면 현재 장비 상태 변화에 집중할 수 있습니다.
2. 선형 회귀 기울기는 시간당 또는 분당 센서 변화 속도를 나타냅니다.
3. p-value는 관측된 기울기가 우연일 가능성을 평가하는 보조 지표입니다.
4. 기울기 임계값과 p-value를 함께 사용해 과도한 경보를 줄입니다.
5. 공정 Recipe 전환도 기울기를 만들 수 있으므로 드리프트로 즉시 단정하지 않습니다.
6. 이후 PyMC 변화점 모델과 계층 모델로 불확실성을 정교하게 다룹니다.
