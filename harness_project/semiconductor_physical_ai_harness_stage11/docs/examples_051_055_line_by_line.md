# 실습 051~055 라인별 해설

## 실습 051 SPC 기준선
1. 기준 구간은 안정 공정으로 간주할 수 있는 초기 데이터입니다.
2. 평균은 공정 중심선을 나타냅니다.
3. 표준편차는 자연 변동 폭을 나타냅니다.
4. 1σ·2σ·3σ 구간은 경보 규칙의 기준이 됩니다.
5. 기준 구간에 이상이 섞이면 관리선도 왜곡됩니다.
6. 실제 현장에서는 공정 엔지니어 승인 후 baseline을 고정합니다.

## 실습 052 X-bar 관리도
1. 여러 샘플을 부분군으로 묶어 평균을 계산합니다.
2. 부분군 평균은 개별 노이즈보다 공정 중심 이동을 잘 보여줍니다.
3. 초기 부분군 평균의 평균이 중심선입니다.
4. 부분군 평균 표준편차의 3배로 관리한계를 만듭니다.
5. 관리한계 밖 점은 특별원인 후보입니다.
6. 부분군은 같은 공정 조건에서 모인 샘플이어야 합니다.

## 실습 053 개별값 관리도
1. 개별값을 그대로 관리도에 표시합니다.
2. 샘플을 묶기 어려운 장비 시계열에 적합합니다.
3. 중심선은 baseline 평균입니다.
4. 상·하한은 평균±3σ입니다.
5. 한 점 위반만으로 고장을 확정하지 않습니다.
6. 이동범위 관리도와 함께 보는 것이 좋습니다.

## 실습 054 이동범위 관리도
1. 이동범위는 연속 두 점의 절대 차이입니다.
2. 평균 이동범위는 단기 변동 수준을 나타냅니다.
3. D4 상수는 부분군 크기 2의 이동범위 관리도 상수입니다.
4. 큰 이동범위는 급격한 센서 변화나 공정 전환을 나타낼 수 있습니다.
5. 개별값은 정상이어도 이동범위가 비정상일 수 있습니다.
6. 시간 간격이 일정한 데이터에서 해석해야 합니다.

## 실습 055 Western Electric 규칙
1. 3σ 밖 한 점은 강한 이상 신호입니다.
2. 3점 중 2점이 2σ 밖이면 지속적인 이동 가능성을 봅니다.
3. 5점 중 4점이 1σ 밖이면 작은 편향의 누적을 찾습니다.
4. 8점 연속 한쪽은 공정 중심 이동을 시사합니다.
5. 규칙을 늘리면 조기 탐지는 좋아지지만 오경보도 증가합니다.
6. 경보는 장비 이벤트와 Recipe 변화와 함께 검토합니다.
