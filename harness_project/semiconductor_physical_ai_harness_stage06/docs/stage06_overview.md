# 6단계 개요: 센서 이상값 탐지와 보정

| 실습 | 주제 | 주요 출력 |
|---:|---|---|
|026|물리 범위 위반 탐지|`physical_range_violations.csv`|
|027|IQR 이상값 탐지|`iqr_outlier_summary.csv`|
|028|Z-score 이상 행 탐지|`zscore_outlier_rows.csv`|
|029|Hampel 필터|보정 데이터·센서별 이상 표시|
|030|보정 품질 비교|방법·센서별 MAE와 RMSE|

## 실무 핵심
이상값은 단순 삭제보다 원인 분류가 먼저입니다. 센서 오류, 통신 오류, 실제 공정 이상, 공정 전환 구간을 구분하고 원본값·탐지 결과·보정값을 모두 추적할 수 있어야 합니다.
