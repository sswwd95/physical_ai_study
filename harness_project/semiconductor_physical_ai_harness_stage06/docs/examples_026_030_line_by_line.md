# 실습 026~030 라인별 해설

## 실습 026 물리 범위 검사
1. 센서의 절대 물리 범위는 명백한 데이터 오류를 빠르게 찾는 기준입니다.
2. `between(low, high)`는 범위 안의 값을 True로 표시합니다.
3. 반전 연산 `~`으로 범위 밖 값을 찾습니다.
4. 시각·Lot·Recipe를 함께 남기면 데이터 발생 맥락을 추적할 수 있습니다.
5. 물리 범위 위반은 센서 단위 오류, 통신 오류, 파싱 오류일 수 있습니다.
6. 공정 관리 한계와 절대 물리 범위는 목적이 다릅니다.

## 실습 027 IQR 이상값 탐지
1. Q1은 하위 25%, Q3는 하위 75% 지점입니다.
2. IQR은 데이터 중간 50%의 폭입니다.
3. Q1-1.5×IQR과 Q3+1.5×IQR을 경계로 사용합니다.
4. IQR은 평균보다 극단값에 덜 민감합니다.
5. 분포가 비대칭이거나 공정 모드가 여러 개인 경우 과검출될 수 있습니다.
6. Lot·Recipe별로 따로 계산하면 공정 조건 차이를 더 잘 반영할 수 있습니다.

## 실습 028 Z-score 이상값 탐지
1. Z-score는 값이 평균에서 표준편차 몇 배 떨어졌는지를 나타냅니다.
2. 절대값 3 이상은 일반적인 이상 후보 기준입니다.
3. 여러 센서의 Z-score를 같은 행에서 비교할 수 있습니다.
4. 평균과 표준편차 자체가 이상값의 영향을 받을 수 있습니다.
5. 정규분포 가정이 약한 센서에는 강건 방법이 더 적합할 수 있습니다.
6. 이상 센서 목록은 다변량 장애 패턴 확인에 유용합니다.

## 실습 029 Hampel 필터
1. 이동 중앙값은 국소 구간의 대표값입니다.
2. MAD는 중앙값 기준 절대편차의 중앙값입니다.
3. MAD는 극단값에 강한 변동성 추정치입니다.
4. 1.4826 계수는 정규분포 표준편차와 규모를 맞춥니다.
5. 임계값을 넘는 값만 이동 중앙값으로 대체합니다.
6. 이상 여부 열을 남겨 원본과 보정값을 구분합니다.

## 실습 030 이상값 보정 품질 비교
1. 완전 데이터와 오염 데이터의 차이로 실제 이상 위치를 정의합니다.
2. 중앙값 대체는 단순하지만 시간 흐름을 반영하지 않습니다.
3. 선형 보간은 앞뒤 시간 관계를 반영합니다.
4. Hampel 필터는 국소 중앙값과 변동성을 사용합니다.
5. MAE와 RMSE는 복원 정확도를 수치로 비교합니다.
6. 센서별로 최적 방법이 다를 수 있으므로 하나의 방법을 모든 센서에 강제하지 않습니다.
