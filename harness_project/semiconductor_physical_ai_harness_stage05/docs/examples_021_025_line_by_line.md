# 실습 021~025 라인별 해설

## 실습 021 결측값 탐지
1. `isna()`는 센서값이 비어 있는 위치를 True로 표시합니다.
2. `sum()`은 True를 1로 계산하여 결측 개수를 구합니다.
3. 결측률은 결측 개수를 전체 행 수로 나누어 계산합니다.
4. 결측률 정렬은 데이터 품질이 가장 나쁜 센서를 먼저 찾게 합니다.
5. 행 단위 결측 여부는 여러 센서가 동시에 끊겼는지 파악하는 출발점입니다.
6. 원본 파일은 읽기 전용으로 사용하고 요약 결과만 별도 저장합니다.

## 실습 022 결측 패턴 분석
1. 각 행에서 어떤 센서가 비었는지 문자열로 기록합니다.
2. 한 행의 결측 센서 개수는 공통 통신 장애 가능성을 보여줄 수 있습니다.
3. 결측 여부가 바뀌는 지점을 이용해 연속 블록을 구분합니다.
4. 시작·종료 인덱스와 시각은 장애 구간 추적에 필요합니다.
5. 블록 길이가 길수록 단순 순간 누락보다 심각한 수집 장애일 수 있습니다.
6. 실제 분석에서는 장비 이벤트 로그와 결측 구간을 함께 비교합니다.

## 실습 023 전방·후방 채우기
1. 전방 채우기는 직전 정상값을 다음 결측 위치에 복사합니다.
2. 데이터 시작 부분에는 직전 값이 없으므로 결측이 남을 수 있습니다.
3. 후방 채우기는 다음 정상값을 이용해 경계 결측을 처리합니다.
4. 대체 여부 열은 원본값과 생성값을 구분하는 데이터 계보 정보입니다.
5. 계단형 센서에는 유용할 수 있지만 빠르게 변하는 센서에는 부적절할 수 있습니다.
6. 결측 처리 후에도 원본 결측 위치를 반드시 보존해야 합니다.

## 실습 024 선형 보간
1. 선형 보간은 결측 구간 양끝 값 사이를 직선으로 연결합니다.
2. `limit_area="inside"`는 양쪽에 정상값이 있는 내부 결측만 보간합니다.
3. 시작과 끝의 결측은 전방·후방 채우기로 보완합니다.
4. 짧고 완만한 센서 결측에는 비교적 자연스러운 결과를 제공합니다.
5. 긴 결측 구간이나 급변 구간에서는 실제 변화를 잃을 수 있습니다.
6. 보간 여부 열을 통해 모델이 생성값을 구분할 수 있게 합니다.

## 실습 025 결측 처리 품질 비교
1. 완전한 데이터는 실제 정답 역할을 합니다.
2. 결측 데이터의 비어 있던 위치만 평가 대상으로 사용합니다.
3. MAE는 평균 절대 오차로 해석이 쉽습니다.
4. RMSE는 큰 오차에 더 큰 벌점을 줍니다.
5. 센서 특성에 따라 최적 처리 방법이 달라질 수 있습니다.
6. 실무에서는 결측 길이, 공정 단계, 센서 속도와 물리 특성을 함께 고려합니다.
