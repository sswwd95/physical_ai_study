# 5단계 개요: 센서 결측값 탐지와 처리

| 실습 | 주제 | 주요 출력 |
|---:|---|---|
|021|센서별 결측 탐지|`missing_value_summary.csv`|
|022|결측 패턴·연속 블록|행 패턴 CSV·블록 CSV|
|023|전방·후방 채우기|처리 데이터와 대체 표시 열|
|024|선형 보간|보간 데이터와 보간 표시 열|
|025|처리 품질 비교|방법·센서별 MAE와 RMSE|

## 실무 핵심
결측값은 무조건 채우는 것이 아니라 발생 원인, 길이, 공정 단계, 센서 물리 특성을 확인한 후 처리해야 합니다. 원본 결측 위치와 처리 방법을 별도 열이나 로그로 남겨야 추적성과 모델 신뢰성을 확보할 수 있습니다.
