# 실습 011~015 라인별 해설

## 실습 011 센서 로그 읽기와 구조 확인
1. `Path`로 입력 파일 위치를 안전하게 계산합니다.
2. `parse_dates`는 시간 문자열을 Pandas 날짜·시간 자료형으로 변환합니다.
3. 필수 열 목록은 분석 코드가 기대하는 데이터 계약입니다.
4. 열이 누락되면 잘못된 분석을 계속하지 않고 즉시 중단합니다.
5. 시작·종료 시각은 데이터 수집 구간을 확인하는 기본 정보입니다.
6. Lot과 Recipe 목록은 후속 그룹 비교의 기준입니다.

## 실습 012 센서 기술통계
1. `describe().T`는 센서별 통계를 행 형태로 보기 좋게 전환합니다.
2. 평균은 전체 중심을, 중앙값은 이상값에 덜 민감한 중심을 나타냅니다.
3. 표준편차는 절대 변동 폭입니다.
4. 변동계수는 평균 크기가 다른 센서들의 상대 변동을 비교합니다.
5. 사분위수는 데이터의 중간 50% 범위를 이해하는 데 사용합니다.
6. 결측 개수는 통계 결과의 신뢰성을 판단하는 기본 정보입니다.

## 실습 013 이동 통계
1. 시계열은 반드시 시간순으로 정렬한 뒤 계산합니다.
2. 30개 샘플은 현재 데이터에서 30초 창을 의미합니다.
3. 이동평균은 짧은 노이즈를 줄이고 추세를 보여줍니다.
4. 이동표준편차는 최근 변동성 증가를 보여줍니다.
5. 잔차는 현재 값이 최근 평균에서 얼마나 벗어났는지 나타냅니다.
6. 초기 5개 미만 구간은 충분한 정보가 없어 NaN으로 남습니다.

## 실습 014 상관관계
1. 피어슨 상관계수는 두 센서의 선형 동조 정도를 -1~1로 표현합니다.
2. 같은 센서의 자기상관은 항상 1이므로 비교 목록에서 제외합니다.
3. 센서 A-B와 B-A는 같은 정보이므로 한 번만 남깁니다.
4. 절댓값 정렬은 양·음 방향과 무관하게 강한 관계를 찾습니다.
5. 진동과 모터 전류의 높은 상관은 공통 부하 변화 가능성을 시사할 수 있습니다.
6. 하지만 상관만으로 원인을 확정할 수 없습니다.

## 실습 015 설비 상태 요약
1. 센서별 교육용 상·하한으로 경보 열을 만듭니다.
2. 한 시각에 몇 개 센서가 동시에 이상인지 계산합니다.
3. Lot별로 경보 행과 평균 센서 상태를 집계합니다.
4. 경보율은 Lot 간 데이터 길이가 달라도 비교하기 쉽습니다.
5. NORMAL/WATCH/ALERT 등급은 보고서 가독성을 위한 교육용 규칙입니다.
6. 실제 현장에서는 제품, Recipe, 장비 상태와 공정 엔지니어 승인을 반영해야 합니다.
