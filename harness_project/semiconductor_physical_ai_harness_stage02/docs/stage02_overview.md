## 하네스 엔지니어링 관점

하네스는 단순히 코드를 생성하는 프롬프트가 아닙니다. 다음 요소를 함께 관리해야 합니다.

1. 입력 계약
2. 설정 계약
3. 실행 순서
4. 로그와 오류 전달
5. 자동 검증
6. 파일 변경 범위
7. 실제 장비와의 안전 경계
