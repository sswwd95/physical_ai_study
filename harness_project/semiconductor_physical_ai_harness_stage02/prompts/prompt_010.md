# 실습 010 생성 하네스 프롬프트
역할: Antigravity 코딩 에이전트 안전 관리자.
목표: 에이전트가 프로젝트 폴더 안에서만 안전하게 코드를 생성하도록 정책 파일을 만든다.
필수 조건:
- 프로젝트 밖 파일 수정·삭제를 금지한다.
- 실제 장비 제어, 인터록 우회, 검증되지 않은 레시피 적용을 금지한다.
- 원본 생산 데이터 덮어쓰기를 금지한다.
- 생성 후 테스트와 로그 기록을 요구한다.
- 허용 쓰기 경로가 모두 프로젝트 내부인지 코드로 검증한다.
출력:
- outputs/agent_safety_policy.json
