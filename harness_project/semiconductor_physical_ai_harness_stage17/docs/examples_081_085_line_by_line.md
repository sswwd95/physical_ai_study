# 실습 081~085 라인별 해설

## 실습 081 불량 라벨 생성
1. 불량 라벨은 모델 학습의 목표값입니다.
2. 품질 점수·온도·진동 규칙을 각각 boolean으로 만듭니다.
3. 하나라도 참이면 생성 불량 라벨을 1로 지정합니다.
4. 기존 검사 라벨과 일치율을 비교해 규칙의 한계를 확인합니다.
5. 규칙 기반 라벨은 빠르지만 검사 장비 라벨을 완전히 대체할 수 없습니다.
6. 라벨 생성 기준은 품질·공정 담당자가 승인해야 합니다.

## 실습 082 센서 구간별 불량률
1. qcut은 센서 데이터를 비슷한 표본 수의 4구간으로 나눕니다.
2. 각 구간의 표본 수와 불량 수를 계산합니다.
3. 불량률이 센서 수준에 따라 변하는지 확인합니다.
4. 단조 증가가 보이면 위험 요인 후보가 될 수 있습니다.
5. 구간화는 연속 정보 일부를 잃습니다.
6. 다음 단계의 회귀 모델로 연속 관계를 정교하게 분석합니다.

## 실습 083 교차표·카이제곱 검정
1. 교차표는 범주형 조건별 정상·불량 개수를 보여줍니다.
2. 카이제곱 검정은 두 범주형 변수가 독립인지 평가합니다.
3. p-value가 작으면 연관성 근거가 있습니다.
4. 기대빈도가 너무 작으면 검정 신뢰도가 낮아질 수 있습니다.
5. 연관성은 인과관계가 아닙니다.
6. Recipe와 Tool의 혼란효과를 별도 모델에서 조정해야 합니다.

## 실습 084 위험비
1. 노출군은 특정 공정 조건을 만족하는 Wafer입니다.
2. 비노출군은 조건을 만족하지 않는 Wafer입니다.
3. 위험비는 두 집단 불량률의 비율입니다.
4. 위험비 1보다 크면 노출 조건의 불량 위험이 더 높습니다.
5. 위험차는 실제 불량률 차이를 퍼센트포인트로 보여줍니다.
6. 표본 수와 신뢰구간 없이 위험비만 단정하지 않습니다.

## 실습 085 불량 분석 대시보드
1. 전체 불량률은 기본 품질 KPI입니다.
2. Recipe·Tool별 불량률은 조건별 차이를 보여줍니다.
3. 위험비는 우선 조사 조건을 정하는 데 도움을 줍니다.
4. 센서 구간별 표는 연속 센서와 불량률 관계를 보여줍니다.
5. 통계적 연관성은 원인 확정이 아닙니다.
6. DOE와 장비 이력 분석으로 인과관계를 확인해야 합니다.
