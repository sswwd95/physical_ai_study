# 14단계 개요: PCA 기반 다변량 모니터링

| 실습 | 주제 | 주요 출력 |
|---:|---|---|
|066|PCA 기준 모델 학습|joblib 모델·메타데이터 JSON|
|067|주성분 점수 모니터링|PC 점수 경보 CSV|
|068|SPE/Q 통계량|잔차 기반 경보 CSV|
|069|센서 기여도|이상 행 기여도 CSV|
|070|PCA 대시보드|HTML·JSON|

## 실무 핵심
PCA 점수는 정상 변동 방향의 이동을, SPE/Q는 정상 모델이 설명하지 못하는 새로운 패턴을 탐지합니다. 두 지표를 함께 사용하면 공정 중심 이동과 상관 구조 붕괴를 구분하는 데 도움이 됩니다.
