# 15단계 개요: 공정 능력지수와 규격 이탈

| 실습 | 주제 | 주요 출력 |
|---:|---|---|
|071|Cp·Cpk|단기 공정 능력 JSON|
|072|Pp·Ppk|장기 공정 성능 JSON|
|073|규격 이탈률·PPM|위반 CSV·요약 JSON|
|074|Lot별 능력 비교|비교 CSV|

## 실무 핵심
Cp/Cpk와 Pp/Ppk는 공정이 통계적으로 안정적이고 측정시스템이 신뢰할 수 있다는 전제에서 해석해야 합니다. 지수만 보지 말고 실제 규격 이탈률, Lot·Recipe 차이, 시간 변화도 함께 확인해야 합니다.
