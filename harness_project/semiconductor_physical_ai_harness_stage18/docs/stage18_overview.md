# 18단계 개요: 로지스틱 회귀 불량 예측

| 실습 | 주제 | 주요 출력 |
|---:|---|---|
|086|로지스틱 회귀 모델 학습|joblib 모델·메타데이터|
|087|분류 성능 평가|예측 CSV·지표 JSON|
|088|임계값 최적화|임계값 비교 CSV·선택 JSON|

## 실무 핵심
불량 예측은 정확도 하나로 평가하면 안 됩니다. 클래스 불균형, 불량 미탐 비용, 재검사 비용을 반영해 Precision·Recall·Average Precision·임계값별 비용을 함께 검토해야 합니다.
