# 9단계 개요: 스케일링·파생 변수·통합 전처리

| 실습 | 주제 | 주요 출력 |
|---:|---|---|
|041|표준화|표준화 CSV·파라미터 JSON|
|042|Min-Max 정규화|정규화 CSV·파라미터 JSON|
|043|Robust Scaling|강건 스케일링 CSV·파라미터 JSON|
|044|파생 변수 생성|변화량·이동통계·복합 지표|
|045|통합 전처리 파이프라인|전처리 특징 CSV·메타데이터 JSON|

## 실무 핵심
스케일링은 학습 데이터에서만 fit하고 검증·운영 데이터에는 transform만 적용해야 데이터 누출을 막을 수 있습니다. 전처리 파라미터와 특징 순서를 모델 버전과 함께 관리해야 합니다.
