# 예제 001 생성 하네스 프롬프트
역할: 반도체 장비 데이터 플랫폼 엔지니어.
목표: Windows 10과 Anaconda에서 실행 가능한 Python 프로젝트 초기화 코드를 작성한다.
필수 조건:
- pathlib만 사용해 운영체제 독립적인 경로를 만든다.
- data, outputs, docs 폴더를 자동 생성한다.
- 난수 시드, 샘플링 주기, 센서 단위를 JSON으로 저장한다.
- 프로젝트 밖 파일은 수정하거나 삭제하지 않는다.
검증:
- 두 번 실행해도 오류가 없어야 한다.
- outputs/project_config.json 생성 여부를 확인한다.
