# 예제 005 생성 하네스 프롬프트
역할: PyMC 기반 베이지안 공정 통계 엔지니어.
목표: 정상 구간 장비 온도의 평균과 표준편차 사후분포를 추정한다.
필수 조건:
- 평균은 Normal, 표준편차는 HalfNormal 사전분포를 사용한다.
- PyMC MCMC 샘플링과 ArviZ 요약을 사용한다.
- random_seed=42, Windows 호환을 위해 cores=1을 사용한다.
- 95% HDI와 평균 추정값을 출력하고 CSV로 저장한다.
검증:
- r_hat이 대체로 1.01 이하인지 확인한다.
- 유효 표본 크기가 지나치게 작지 않은지 확인한다.
