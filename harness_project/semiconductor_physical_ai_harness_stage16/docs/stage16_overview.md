# 16단계 개요: 공정 능력 불확실성과 비정규 분포

| 실습 | 주제 | 주요 출력 |
|---:|---|---|
|076|정규성 검정|정규성 요약 CSV|
|077|비정규 공정 능력|정규·분위수 지수 비교 CSV|
|078|Bootstrap Cpk|95% 신뢰구간 CSV|
|079|불확실성 비교|권장 방법 비교 CSV|
|080|종합 판정 리포트|CSV·HTML·JSON|

## 실무 핵심
공정 능력지수는 하나의 숫자가 아니라 분포 가정과 표본 불확실성을 포함해 해석해야 합니다. 정규성이 약한 경우 비정규 지수를 검토하고 Bootstrap 신뢰구간으로 보수적인 하한을 확인해야 합니다.
