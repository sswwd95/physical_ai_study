# 13단계 개요: 다변량 공정 모니터링

| 실습 | 주제 | 주요 출력 |
|---:|---|---|
|061|다중 센서 Z-score|센서별 경보 CSV|
|062|Hotelling T²|다변량 경보 CSV|
|063|경보 결합|통합 경보 등급 CSV|
|064|공정 상태 점수|0~100 상태 점수 CSV|
|065|다변량 대시보드|HTML·JSON|

## 실무 핵심
개별 센서가 관리한계 안에 있어도 여러 센서가 동시에 조금씩 이동하면 공정 상태가 달라질 수 있습니다. 다변량 모니터링은 센서 간 상관관계를 반영해 이러한 조합 이상을 탐지합니다.
