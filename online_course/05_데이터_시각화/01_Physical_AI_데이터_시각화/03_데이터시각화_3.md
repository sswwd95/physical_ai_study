# 데이터 시각화 3
## 학습 내용
### 코드 재사용 방식
- 코드 복사보다 필요한 부분을 골라 재사용하는 흐름 중심 실습
- Python 녹화 5일 차의 코드를 재사용하며, 필요한 부분만 가져와 새 코드를 구성
- `x_train`, `y_train` 생성 코드 구성
- 데이터 불러오기 코드 중 필요한 부분만 선택하고, 불필요한 `validation` 데이터나 `column` 조회 등은 가져오지 않아도 됨
- 필요한 코드를 골라 재사용할 수 있어야 한
- 그룹화에 필요한 코드는 가져오되, 단순 조회 코드는 필요하지 않을 수 있음
