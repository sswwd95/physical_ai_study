# 데이터 시각화 1
## 학습 내용
### Physical AI 데이터 시각화
- Physical AI에서 다루는 데이터는 연속 데이터하고, 연속 데이터를 시각화하는 방법을 보여주겠음
- ROS에는 명령어로 데이터를 확인할 수 있는 GUI가 제공되지만, 이는 주로 개발자가 보는 용도
- 고객에게 데이터를 공개하거나 ROS에서 제공하지 않는 시각화가 필요한 경우를 위해 Python 시각화 라이브러리를 실습함
- 데이터 시각화 결과를 웹 기반 모니터링 화면으로 확장 가능
### Matplotlib 시작
- Python 기본 데이터 시각화 라이브러리 `matplotlib`
- 보통 `matplotlib` 전체를 직접 사용하기보다 `pyplot`을 `plt`라는 약어로 가져옴
```python
import matplotlib.pyplot as plt
```
