# 데이터 시각화 2
## 학습 내용
### 로봇 센서 데이터 모니터링
- Valt로 데이터를 시각화하면 그래프가 계속 바뀌어 복잡하게 느껴질 수 있음
- 자율주행 로봇은 센서 데이터와 상태 변화가 비교적 단순하지만, 관절 로봇은 선택 가능한 모니터링 항목이 훨씬 많음
- 처음 접하는 로봇은 어떤 데이터를 모니터링할 수 있는지 목록을 확인하고 학습할 필요가 있음
- 로봇마다 사양과 토픽이 다르지만, 자율주행 로봇은 어느 정도 표준화된 토픽 옵션이 있어 비교적 쉽게 찾을 수 있음
- 그래프 모니터링 항목과 TF 존재 여부 확인
### TF 복잡도
- 자율주행 로봇의 TF는 비교적 단순하지만 관절 로봇의 TF는 복잡
- 짐벌과 같은 개념이 들어가면 TF 구성이 더 까다로워질 수 있음
