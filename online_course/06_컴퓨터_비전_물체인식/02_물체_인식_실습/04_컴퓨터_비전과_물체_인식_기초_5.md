# 컴퓨터 비전과 물체 인식 기초 5
## 학습 내용
### 코드 조합과 프로젝트 확장
- 여러 코드를 조합하면 합성·창작 프로젝트로 확장가능
- 주피터 노트북보다 VS Code를 사용하면 코드 변경을 비교하기 좋음
### VS Code에서 코드 비교
- VS Code에서 `New File` → `Python File`로 파일 생성 및 저장
- 기존 코드를 복사해 저장한 뒤 수정된 코드를 다시 저장하면 타임라인으로 변경 내용을 비교가능
- 이전 코드와 변경된 코드의 차이를 확인할 수 있으며, 변수 설정과 마우스 상태 효과는 같고 `swap` 함수가 없어지는 변경을 예로 들기 시작
