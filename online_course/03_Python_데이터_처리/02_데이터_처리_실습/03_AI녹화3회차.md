### CSV와 Pandas
- Pandas 기반 CSV 파일 로드
- AI Hub의 데이터 분석 실습용 CSV 활용. 다운로드를 위한 회원가입 필요
- CSV는 엑셀과 확장자가 다를 뿐 엑셀로 열 수 있는 표 형식의 파일
### 확인된 코드
```python
import pandas as pd
df = pd.read_csv("파일_경로")
```
- `pd.read_csv()`로 CSV 파일을 읽고 데이터프레임을 만들 수 있음
- 센서 데이터가 CSV 형태로 저장되는 경우 CSV 기반 처리 가능
