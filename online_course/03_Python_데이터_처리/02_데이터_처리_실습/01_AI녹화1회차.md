# AI녹화 1회차
## 학습 내용
### 임의 데이터와 변수의 관계
- 실습 데이터는 임의 생성한 샘플 데이터
- `X`: 입력 변수, `Y`: 입력에 따라 값이 결정되는 종속 변수
- `X`가 특정 값일 때 `Y`가 어떤 값이 되는지 좌표값으로 만들어 관계의 개형을 확인. 이 좌표값은 특정 현상을 의미하는 실제 데이터가 아니라 샘플을 만들기 위한 임의 데이터
### 머신러닝·딥러닝 흐름에서의 위치
전체 흐름:
1. 데이터 전처리
2. 모델 디자인
3. 모델 실행 및 예측
4. 평가
임의 데이터 생성은 전체 머신러닝 흐름에서 데이터 준비 단계에 해당. 실제 데이터 정제보다는 관계 확인을 위한 샘플 데이터 구성.
