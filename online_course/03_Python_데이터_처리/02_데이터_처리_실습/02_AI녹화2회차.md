## 학습 내용
### 중간 데이터 확인
- 데이터 분석 중간중간에 변수가 어떻게 구성되었는지 확인
- `head()`를 사용하면 데이터의 상위 5개 정도를 확인할 수 있고, 더 많은 행을 보고 싶으면 조회 개수를 지정가능
- 주피터 노트북은 데이터가 잘 합쳐졌는지, 특정 변수에 어떤 값이 들어갔는지 중간 결과를 바로 확인하기 쉬워 데이터 분석에 유용
### Iris 데이터셋
- `iris` 변수에 데이터프레임이 들어가며, 꽃받침 길이와 꽃잎 크기 등의 특성으로 꽃의 종을 다루는 데이터
- Seaborn에도 같은 Iris 데이터셋이 있으며, 다음과 같이 불러올 수 있음
```python
import seaborn as sns
iris = sns.load_dataset("iris")
iris
```
