# 결측치 3
## 학습 내용
### 소켓 통신 흐름
- 서버 소켓 객체와 클라이언트 연결 주소를 변수에 할당하고, 서버에서 보낸 데이터와 클라이언트가 받은 데이터를 각각 출력
- 통신이 끝나면 소켓을 종료
- 코드 구조와 각 줄의 실행 흐름을 함께 추적하는 코드 리뷰
### 멀티프로세싱과 TCP/IP·UDP
- Python 멀티프로세싱 코드, 출력 코드, TCP/IP 서버 통신 코드 구분
- `127.0.0.1` 로컬 통신과 외부 주소 기반 통신 방식 비교
- 같은 PC 한 대에서 사용하는 경우와 다른 PC와 통신하는 경우의 주소 설정이 다름
- UDP 통신 코드도 제공했으므로 직접 실행해 보
### 파일 전송과 주의사항
- `pip install` 및 바이너리 파일 빌드 관련 내용이 나오지만, 해당 빌드는 이 과정에서 굳이 생략 가능
