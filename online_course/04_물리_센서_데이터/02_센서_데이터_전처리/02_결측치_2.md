# 결측치 2
## 학습 내용
### 센서별 프로세스 분리
- 센서별로 프로세스를 분기하는 것이 일반적으로 적절
- 프로세스가 종료되면 그 프로세스에 속한 스레드도 함께 종료
- 여러 센서의 스레드를 하나의 프로세스에 몰아넣으면, 알 수 없는 이유로 해당 프로세스가 종료될 때 모든 센서가 작동하지 않을 수 있음
- 그러면 로봇이 아무 동작도 하지 못하는 상황이 될 수 있으므로 센서는 프로세스별로 분기필요
### 프로그램·프로세스·소스 코드
- 프로그램·프로세스 개념에서 소스 코드 구조로 학습 범위 확장
- API와 소스 코드는 크게 다르지 않음
- 라이다 센서 코드 예제를 통한 센서 데이터 처리 흐름
