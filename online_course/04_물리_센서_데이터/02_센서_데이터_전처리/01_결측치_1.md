# 결측치 1
## 학습 내용
### 라이브러리의 특징과 역할
- 라이브러리는 기본적으로 독립적인 구성 가능. 실제 환경에서는 다른 라이브러리의 자료형이나 기능을 의존하는 경우도 존재
- 응용 프로그램이 라이브러리를 능동적으로 사용하며, 프로그래밍에서 특정 기능을 수행하도록 필요한 역할을 제공
- 라이브러리는 반복 코드 감소를 위한 재사용 가능한 클래스·함수 형태로 구성
- PyTorch와 ROS도 클래스 중심으로 구성되어 있고 클래스 안의 함수를 가져다 씀
- 이미 만든 함수를 재활용하면 프로그램 제작 시간과 노력을 줄일 수 있음
### 결측치 처리와 Physical AI 데이터
- 결측치를 평균으로 채우는 작업처럼 라이브러리 함수를 사용하면 복잡한 처리를 간단히 수행가능
- 센서 데이터는 실시간으로 연속적으로 발생하고 양도 많기 때문에, 반복 작업을 함수 호출로 처리하는 기능이 특히 중요
