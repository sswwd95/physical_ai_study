# 물리세계 3
## 학습 내용
### 로봇 재부팅과 자원 문제
- 로봇도 컴퓨터의 연장이므로 메모리 누수나 자원 고갈 문제가 발생가능
- 센서·데이터 감지 이상 발생 시 재시작 시점과 복구 전략 고려 필요
### 운영체제와 설정
- 부팅할 때 불러오는 설정이 저장되는 위치하면서, Ubuntu에는 Windows의 레지스트리와 같은 것이 없고 다른 설정 영역에 저장됨
- Docker, CPU, Linux 개념으로 학습 범위 확장
### CPU와 Linux
- 로봇에는 컴퓨터가 들어가므로 로봇의 ‘뇌’에 해당하는 것은 CPU
- Linux는 Windows나 iOS처럼 하나의 제품만을 가리키는 것이 아니라 종류가 매우 다양함
