# ROS 1
## 학습 내용
### 서비스와 Request
- 물체를 움직이려면 힘을 가해야 하며, 이 명령을 서비스로 전달
- 서비스의 `Request`가 명령을 전달하는 부분
- ROS2 Service Request를 이용한 움직임 명령 전달 구조
### 토픽과 Response
- 물체가 명령을 받으면 즉시 목표 속도로 움직이는 것이 아니라 속도가 단계적으로 올라감
- 속도 변화 같은 상태는 토픽으로 모니터링가능
- 동작 상태가 되면 `Response`로 응답함
- 실제 물체는 마찰과 공기 저항의 영향으로 목표 속도 유지를 위한 지속적인 제어 입력 필요
- 등속 운동을 유지하기 위해 토픽으로 상태를 모니터링하고 엔코더를 통해 계속 힘을 줄 수 있음
