# ROS 3
## 학습 내용
### Parameter server
- 설정값이 없으면 `depth`가 기본값 10으로 들어감
- 로그를 통해 parameter server에 값이 제대로 기록되었는지 확인
- Parameter Server 설정 함수와 콜백 구성. 서버가 없을 때 기본값 0 적용 사례
- 노드가 실행 중인 상태에서도 parameter server의 설정을 변경가능
- parameter server가 업데이트되는 상황을 로그로 확인하도록 구성
### QoS 프로필
- 토픽은 주기적으로 데이터를 전달하고 불특정 다수에게 발행하는 특성이 있음
- QoS 설정을 조정하면 같은 네트워크에서 특정 QoS 프로필에 맞는 subscriber만 토픽을 구독하거나 echo가능
- QoS 프로필을 라디오 주파수에 비유하여, 같은 설정을 맞춘 대상만 데이터를 받을 수 있게 하는 개념
- QoS 설정 상태를 로그로 출력해 확인
