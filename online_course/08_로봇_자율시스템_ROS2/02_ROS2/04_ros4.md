# ROS 4
## 학습 내용
### 서비스 콜백과 Request
- 서비스에서 사용하는 함수가 서비스 콜백 함수이며, Request의 `arithmeticOperator` 값을 읽음
- `arithmeticOperator`의 자료형은 `int`이고, operator에서 전달한 랜덤 숫자가 해당 Request 변수로 들어옴
- 코드 정의를 확인할 때 VS Code에서 F12를 누르면 함수 정의 위치로 이동가능
### 산술 연산과 예외 처리
- 랜덤 숫자에 따라 if 조건문을 실행하고, 토픽으로 받은 값에 대해 더하기·빼기·곱하기·나누기를 수행
- 나눗셈에서 나누는 값이 0인 경우 예외 처리를 수행
- 조건에 해당하지 않는 값이 들어오면 미리 정의한 값 중 하나를 보내도록 구성했음
- 정수형 Request와 실제 전달 값의 관계 확인
