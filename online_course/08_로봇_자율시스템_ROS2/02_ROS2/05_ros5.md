# ROS 5
## 학습 내용
### 노드 연결과 실행
- 이름이 일치하지 않아 실행되지 않던 부분을 수정하고 CMake 리스트를 고친 뒤 빌드하면 동작함
- 여러 노드가 서로 토픽과 서비스를 주고받는 구조를 만들고, 이를 시각화 도구로 모니터링가능
### 여러 노드 실행과 Parameter server
- source·install·setup 명령 반복을 줄이기 위한 다중 노드 동시 실행 방식
- 먼저 parameter server를 만드는 작업을 시작
- 패키지 아래 `param` 폴더 생성 후 YAML 설정 파일 추가
- YAML 파일에 값을 작성하면 parameter server에서 해당 설정값을 불러올 수 있음
- `custom_depth` 설정값을 Parameter Server에서 읽는 흐름
