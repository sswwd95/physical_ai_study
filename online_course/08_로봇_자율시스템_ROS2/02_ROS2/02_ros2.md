# ROS 2
## 학습 내용
### 토픽·서비스·액션 관계
- 토픽에서 publisher와 subscriber가 항상 둘 다 필요한 것은 아니며, subscriber만 켜 두고 토픽을 임의로 발행할 수도 있음
- 서비스도 서버와 클라이언트가 항상 모두 필요한 것은 아니
- 토픽을 직접 발행해 로봇 동작에 개입하거나 조작가능
- 액션은 서비스와 토픽이 결합된 형태라 더 사용하기 어려움하며, 액션을 직접 만들어 보는 실습을 진행
### 액션 실습 흐름
- 액션 서버·클라이언트 파일을 작성하고, 콘솔 명령어를 추가하
- 코드 작성 후 `ros2_ws` 이동 및 `colcon build`를 통한 워크스페이스 빌드
- 빌드가 완료된 뒤 실제 테스트를 실행
