# 로봇 주행·조작 AI 기초 1
## 학습 내용
### 보드 변화와 Docker
- Raspberry Pi 보드는 세대가 바뀌며 새 모델이 계속 출시되고, 보드가 바뀔 때마다 최적화 문제가 생길 수 있음
- Docker를 사용하면 새 보드를 기존 로봇에 적용할 때 발생하는 최적화 이슈에 대응하기 쉬움
- 로봇 개발자라면 Docker를 어느 정도 사용활용 역량 필요. 앞으로 로봇 개발에서 Docker가 필수에 가까워질 것
- 임베디드의 보수적인 개발 방식과 계속 발전하는 AI 사이를 연결하는 로봇에서 Docker가 중요
### 프로그램 아키텍처
- 네비게이션을 구현하려면 Docker 컨테이너 안의 프로그램 아키텍처를 잘 설계필요
- 청소 로봇·서빙 로봇의 센서, 제어, 통신 모듈을 기준으로 프로그램 아키텍처 구성 검토
- 로봇별 센서 구성 차이. 예: 2D 스캐너, 라이다 센서를 장착한 서빙 로봇
