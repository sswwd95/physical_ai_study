# 로봇 주행·조작 AI 기초 2
## 학습 내용
### 신경망과 Physical AI 입출력
- 신경망을 만들 때 입력 데이터의 숫자 구조가 서로 맞아야 함
- Physical AI에서는 센서 데이터 개수와 그 데이터로 만든 행렬의 인덱스·컬럼 구조가 신경망 입력과 맞아야 함
- 자율주행의 출력은 `cmd_vel`이어야 하며, 센서 데이터와 `cmd_vel`을 연결하는 신경망이 필요
- 사전학습 모델을 가져와 자체 데이터로 파인튜닝하는 방식
### 학습 코드의 흐름
- 본 코드와 비교하며 전처리 부분은 줄어들고 데이터 로드 중심으로 구성됨
- 학습 방법과 코드 실행 과정 확인
