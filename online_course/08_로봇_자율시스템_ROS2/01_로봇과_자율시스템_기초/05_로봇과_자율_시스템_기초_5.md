# 로봇과 자율 시스템 기초 5
## 학습 내용
### ROS 실습 오류 대응
- ROS 실습에서 빌드가 되지 않거나 실행되지 않는 문제가 생길 수 있음
### ROS 인터페이스 패키지
- ROS를 통신 프로토콜로 인터페이스 패키지를 만드는 과정을 시작
- 인터페이스 패키지는 C++ 패키지로 만들어야 함
- 패키지 생성 명령어를 사용하면 XML, `CMakeLists`, `setup.py` 같은 구성 파일이 자동 생성
- 명령어를 사용하지 않고 직접 만들면 이 파일들을 일일이 작성해야 하므로 자동 생성 명령어를 사용하는 것이 편리
- 생성된 폴더 트리에서 소스 코드 위치 확인
