# 로봇과 자율 시스템 기초 3
## 학습 내용
### Windows Docker 환경의 시각화
- Windows에서 Docker를 실행할 때 시각화를 위해 X Launcher를 설치하고 실행필요
- X Launcher 미실행 시 Docker 내부 GUI 시각화가 표시되지 않을 수 있음
- ROS가 시각화 도구를 제공
### ROS 시각화와 아키텍처
- 3D SLAM 시각화와 ROS 노드·프로세스 연결 구조
- 각 프로세스가 어떻게 연결되어 있는지 아키텍처를 그림으로 확인가능
- ROS 시스템 구조 파악에 유용한 시각화
### 가상 환경과 ROS 실습
- VM·VirtualBox 등 한 OS 안에서 다른 OS를 실행하는 가상 환경
