# 로봇과 자율 시스템 기초 4
## 학습 내용
### ROS 실습 환경 준비
- ROS 실습이 어려울 수 있으므로 먼저 환경 설정을 준비필요
- Ubuntu 네이티브 환경과 Docker 환경의 폴더 구조 차이 존재
- X Launcher를 켜고 Docker를 실행하
- Docker 환경에서 VS Code의 Dev Containers 확장이 필요할 수 있으며, 설치되지 않은 경우 `Dev Containers`를 검색해 설치하
- 설치가 진행되는 동안에는 영상을 잠시 멈춰도 됨
- VS Code의 `Attach Running Container`를 이용한 실행 중 컨테이너 연결
