# 33-노멀방정식과벡터변수에대한선형회귀
## 핵심 내용
정규방정식/노멀방정식을 실제 코드로 계산하기 위해 디자인 행렬을 구성하는 방법.
- 데이터 행렬에서 각 데이터는 하나의 행(row)에 배치
- 차이점은 원본 데이터값 자체가 아니라, 입력 데이터를 여러 기저 함수에 넣어 얻은 값들이 한 행에 나열된다는 점
- 디자인 행렬 구성 후 `transpose`, 행렬곱, 역행렬, 정답 벡터 곱을 순서대로 적용해 가중치 벡터 `W` 계산
- 기저 함수를 쓰지 않는 경우 디자인 행렬은 원본 `X`에 가까우나, 절편항 `W0`와 곱해질 첫 열 `1`을 추가필요
- 벡터 변수에 대한 선형회귀에서도 행렬 형태를 맞추고 정규방정식으로 `W`를 한 번에 구하는 흐름이 핵심
## 코드 및 실습
정규방정식 실험 코드.
주요 라이브러리·요소:
- Python
- NumPy
- 행렬 연산: transpose, matrix multiplication, inverse
- 다항 기저 함수/다항 특성
코드 구조와 로직:
- `X_train`을 `reshape(-1, 1)`로 열 벡터 변환
- `np.ones(N).reshape(-1, 1)`로 절편항용 1 열 생성
- `np.append(.., axis=1)` 또는 `np.hstack(..)`으로 열 방향 결합 후 디자인 행렬 생성
- 다항 기저 사용 시 `for p in range(M)`으로 차수를 순회하며 `np.power(..)`로 거듭제곱 특성 생성 및 행렬 누적
- 디자인 행렬 예시는 열이 `x^0`, `x^1`, `x^2`, `x^3` 형태로 구성됨
- 화면에 표시된 예시 디자인 행렬은 첫 열이 모두 `1`, 이후 열은 `0.1111`, `0.0123`, `0.0014`처럼 입력값의 거듭제곱으로 채워짐
- 이후 계산은 정규방정식 형태:
 - `X.T @ X`
 - `np.linalg.inv(..)`
 - 다시 `X.T`
 - 정답 벡터 `T` 또는 `y_train` 곱
주요 이름:
- `X_train`
- `N`
- `M`
- `W`
- `np.ones`
- `reshape(-1, 1)`
- `np.append`
- `np.hstack`
- `np.power`
- `range(M)`
- `transpose` / `.T`
- `inverse` / `np.linalg.inv`
## 실행 결과
디자인 행렬 출력 형태:
- 열: `x^0`, `x^1`, `x^2`, `x^3`
- 첫 열은 절편항용 `1`
- 뒤 열은 입력값의 1승, 2승, 3승 값으로 구성
- 예시 값은 `0.1111`, `0.0123`, `0.0014`처럼 다항 차수가 올라갈수록 해당 입력값의 거듭제곱으로 계산됨
## 학습 메모
- 절편항을 위해 `X`의 첫 열에 `1`을 추가해야 한는 점 중요
- 기저 함수를 쓰지 않는다면 디자인 행렬은 사실상 `X` 행렬이지만, 절편항 열 추가는 별도로 필요
