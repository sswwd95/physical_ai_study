# 31-규제
## 핵심 내용
다항식 차수를 높이면 train data를 모두 지나가려 하면서 곡선 굴곡이 심해지고 회귀 계수 `W`가 매우 증가. 이런 현상을 overfitting.
회귀 결과 평가는 RMS(Root Mean Square)를 사용. 기존 제곱 오차 합은 제곱되어 있고 데이터 수가 많으면 값이 커지므로, 제곱을 상쇄하기 위해 루트를 씌우고 데이터 개수 `n`으로 나눠 평균적인 에러를 확인.
차수 0~8 피팅 결과에서 train error는 계속 줄지만, test error는 6차부터 증가하기 시작하고 8차에서 크게 증가. train error 감소만으로 충분하지 않으며, test data의 error 감소도 중요.
Overfitting 해결 방법은 두 가지.
- 추가 데이터 수집
- regularization, 즉 규제화를 사용
규제화는 목적 함수에 계수 크기에 대한 penalty term을 더해 `W`가 지나치게 커지는 것을 억제. L2 regularization은 `W`의 각 요소를 제곱해 더한 값을 목적 함수에 추가. `lambda`는 이 penalty가 목적 함수에 얼마나 영향을 줄지 정하는 하이퍼파라미터.
규제화는 penalty를 더한 비제약 최적화 문제로 볼 수도 있고, `W`의 크기가 어떤 `eta`보다 커지지 못하게 하는 제약 최적화 문제로도 볼 수 있음. `lambda`와 `eta`를 잘 조정하면 두 관점은 같은 문제를 품.
L1 norm 제약은 2변수 그림에서 마름모 영역을 만들고, L2 norm 제약은 원형 영역을 생성. 제약이 강해질수록 해는 원래 목적 함수의 최적점으로 가지 못하고 허용된 영역 안에서 가장 가까운 지점에 유지.
## 코드 및 실습
주요 라이브러리·요소:
- Python
- NumPy
- SciPy optimize
- Matplotlib 계열 그래프
- Jupyter Notebook
실습 흐름:
- `rms` 함수를 선언
- 0차부터 8차까지 for loop를 돌며 각 차수별 optimization을 수행
- 결과를 테이블과 그래프로 그려 train/test RMS 변화를 비교
- 3차까지는 test error가 줄지만, 6차부터 test error가 증가해 overfitting이 시작됨을 확인
- 8차 피팅에서는 계수 값이 만 단위, 10만 단위로 커지는 것을 확인
- 에러 함수 뒤에 L2 regularization 항을 추가
- `W0`, 즉 y절편은 규제항에 포함할지 선택하는 옵션을 설정. 보통 `W0`는 규제하지 않는 경우가 많음
- `regularization` 변수를 `L1` 또는 `L2`로 바꾸고, `lambda` 값을 조정하면서 제약 영역과 목적 함수 contour가 어떻게 바뀌는지 시각화
핵심 코드 구조:
```text
regularized_error = error + (lambda / 2) * ||W||_2^2
```
절편 제외 옵션:
```text
W0를 penalty 계산에 포함할지 선택
```
## 실행 결과
- 0차 피팅은 평평한 선
- 1차 피팅은 직선
- 3차 피팅은 원래 곡선을 비교적 안정적으로 근사
- 8차 피팅은 train point를 모두 지나가려 하면서 굴곡 증가
- 8차 계수는 만 단위, 10만 단위까지 증가
- L2 regularization을 적용하면 8차 모델도 `W`가 10 안쪽 정도로 제한되고, 곡선이 부드럽게 근사
- L1/L2 규제를 제약 조건 관점과 penalty 관점으로 그렸을 때 같은 최적점을 구함을 확인
