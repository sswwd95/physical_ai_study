# 32-정규방정식
## 핵심 내용
정규방정식은 경사하강법을 반복하지 않고, 목적 함수를 최소화하는 최적의 `W`를 한 번에 구하는 방법. 핵심 근거는 최적화 필요조건. 에러 함수가 `W`에 대한 다변수 함수이므로, 이를 미분해서 0이 되는 지점을 탐색.
가설은 `w^T φ(x)` 형태. `φ`는 기저 함수 벡터이며 입력 데이터를 기저 함수 개수만큼의 특징으로 변환. 다항 기저는 `φ0=x^0`, `φ1=x^1`, ..., `φM-1=x^(M-1)` 형태. 기저 함수 미사용 시 입력 벡터 `x`의 기존 특징을 그대로 사용.
스칼라를 벡터로 미분할 때 결과를 열 벡터로 쓰는 분모 레이아웃과 행 벡터로 쓰는 분자 레이아웃이 있으며, 한 식 안에서는 레이아웃을 통일 필요. 목적 함수 미분에서 분자 레이아웃을 사용.
목적 함수의 각 항은 합성 함수 미분으로 처리. 제곱 오차를 미분하면 오차항이 나오고, `w^T φ(x)`를 `w`로 미분하면 `φ^T`가 나옴. 전체 gradient를 0으로 두고 식을 정리하면 정규방정식 형태로 연결.
디자인 매트릭스는 각 데이터에 기저 함수를 적용한 값을 행으로 모은 행렬. 행 방향은 데이터 `N`, 열 방향은 기저 함수 또는 특징 `M`. 외적 합과 행 조합 관점을 이용해 시그마 형태의 벡터·행렬식을 디자인 매트릭스 곱으로 변환.
최종적으로는 양변에 전치를 취하고, 행렬곱 전치 규칙 `(AB)^T = B^T A^T`를 사용해 식을 정리. 이후 역행렬을 곱해 `W`를 구하는 형태가 됨.
하지만 실제 데이터에서는 디자인 매트릭스와 `W`를 곱한 결과가 타깃 `T`와 정확히 같을 수 없음. 모든 점을 정확히 지나는 모델이 아니기 때문. 그래서 완전한 역행렬 문제가 아니라 Moore-Penrose pseudo inverse와 최소제곱 문제로 해석.
기하학적으로는 타깃 벡터 `T`가 `N`차원 공간의 임의 벡터이고, 디자인 매트릭스의 열 벡터들이 만드는 선형조합 공간은 보통 더 낮은 차원의 부분공간. `φW`가 이 부분공간 위에서 `T`에 가장 가까운 벡터가 되도록 고르는 것이 최소제곱 선형회귀. 차 벡터 `T - φW`의 길이가 가장 짧아지는 지점을 찾는 문제이며, 이것이 기존 cost function과 같은 의미.
## 수식 및 구현
주요 요소:
- Python
- NumPy
- Jupyter Notebook
- 선형대수 행렬 연산
핵심 변수/개념:
- `W`: 회귀 계수 벡터
- `φ(x)`: 기저 함수 벡터
- design matrix: 각 데이터에 기저 함수를 적용한 행렬
- `T`: 타깃 벡터
- `N`: 데이터 개수
- `M`: 기저 함수 또는 특징 개수
- Moore-Penrose pseudo inverse
핵심 수식 흐름:
```text
error(W)를 W로 미분
gradient = 0
design matrix 형태로 정리
역행렬 또는 pseudo inverse로 W 계산
```
