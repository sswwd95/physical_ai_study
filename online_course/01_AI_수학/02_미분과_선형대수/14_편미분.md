# 14-편미분
## 학습 개요
다변수 함수에서 각 독립변수 변화에 따른 출력의 민감도를 이해.
## 학습 포인트
일변수 함수에서는 x가 변할 방향이 좌우로 제한되지만, 다변수 함수에서는 특정 위치에서 독립변수가 변할 방향이 무수히 많음. 따라서 여러 입력 변수가 변할 때 y가 얼마나 변하는지 민감도를 생각해야 하며, 이것이 편도함수로 연결.
편미분은 다변수 함수에서 특정 변수 하나만 변화시키고 나머지 변수는 고정한 채 변화율을 구하는 방식. 변수가 2개이면 각 변수 방향으로 1변수 함수를 두 개 만들 수 있고, 변수가 n개이면 변수 개수만큼의 1변수 함수와 미분 계수가 발생.
편미분은 일반 미분의 `d`와 구분되는 라운드 기호로 표기. 여러 변수 중 특정 변수에 대한 미분 의미.
## 핵심 정리
- 1변수 함수는 한 방향 축의 변화, 2변수 함수는 동일 지점에서도 여러 독립변수 방향의 변화 가능
- 일반적인 순간 변화율 개념을 다변수 함수 전체 방향에 바로 적용하기 어렵기 때문에, 이 하나의 변수만 바꾸는 제한된 방식으로 미분을 학습
- 특정 점에서 `x`를 고정하고 `y`만 바꾸면 `y` 방향의 1변수 함수가 생기고, 반대로 `y`를 고정하고 `x`만 바꾸면 `x` 방향의 1변수 함수가 발생
- 임의 방향의 변화율은 방향 도함수로 명칭
- 편도함수를 구하는 과정이 편미분이며, 편미분 계수는 변수 개수만큼 생성
## 예제: 2변수 함수 편미분
`x^2 + 3xy + y - 3` 형태의 2변수 함수를 예시.
- `x`로 편미분할 때는 `y`를 상수처럼 취급
- `x^2`는 `2x`가 되고, `3xy`는 `3y`가 됨
- `y`로 편미분할 때는 `x^2`가 상수라 사라지고, `3xy`는 `3x`, `y`는 `1`이 됨
- 상수항은 어느 변수로 미분해도 소거
## 신경망 시각화 예시
편미분이 실제 연구에서 사용되는 사례로 이미지 분류 신경망.
- 224×224 이미지가 입력되고, 출력은 여러 클래스 중 하나의 점수로 나옴
- 로트바일러 이미지를 예로 들어, 특정 클래스 출력값을 입력 픽셀 전체에 대해 편미분가능
- 각 픽셀의 편미분 계수는 해당 픽셀이 클래스 판단에 미치는 민감도 의미
- 편미분 계수가 큰 픽셀을 이미지처럼 재배열하면 신경망이 어느 위치에 민감하게 반응했는지 시각화가능
- 로트바일러 예시에서 눈 위의 밝은 점과 같은 특징이 분류 판단에 크게 기여하는 것으로 해석 가능
- 편미분 개념을 역으로 활용한 연구 사례
## 다변수 함수의 연쇄 법칙
지난 시간의 1변수 합성 함수 체인 룰을 다변수 함수로 확장.
- `t` 변화 → `x`, `y` 변화 → 최종 출력 `w` 변화 구조
- `t -> x -> w` 경로의 변화율과 `t -> y -> w` 경로의 변화율을 각각 곱한 뒤 더하면 전체 변화율이 됨
- 이를 수형도로 표현하고, 출발점에서 출력까지 가는 각 경로의 미분 계수를 곱한 뒤 한 점으로 모일 때 더함
- 여러 경로의 미분값이 더해지는 구조를 직관적으로 이해
- 변수가 3개 이상이어도 같은 방식으로 더해지는 항이 늘어날 뿐이며, 머신러닝과 딥러닝에서 다변수 함수의 연쇄 법칙이 중요하게 사용된
