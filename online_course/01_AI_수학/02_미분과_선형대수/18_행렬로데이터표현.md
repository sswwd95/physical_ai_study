# 18-행렬로데이터표현
## 학습 포인트
행렬을 이용한 테이블형 데이터·이미지·문서 표현. 테이블의 행은 개별 데이터, 열은 데이터 항목(특징). 한 데이터는 행벡터, 열은 특징벡터. 사람별 키·몸무게·혈압을 행렬로 구성.
데이터 개수 `N`, 데이터 차원 `D` 기준 테이블형 데이터 행렬은 `N × D` 형태. 행은 개별 데이터 레코드, 열은 키·몸무게·혈압 같은 특징.
## 이미지 데이터 표현
뱀 이미지를 예로 들어 이미지가 여러 픽셀 값으로 구성됨. 높이 `H`와 너비 `W`에 해당하는 픽셀 값을 행렬에 담을 수 있고, RGB 채널까지 고려하면 채널 방향으로 값이 3개 더 발생.
여러 장의 행렬로 구성되는 고차원 데이터 구조는 Tensor. 채널 위치에 따라 channel first와 channel last 방식으로 구분.
## 문서 데이터 표현
문서를 숫자로 표현하기 위해 단어장을 생성. 문서에서 많이 나오는 단어들을 단어장으로 구성하고, 문서 안의 각 단어가 단어장에서 몇 번째 단어인지 인덱스로 표시. 그러면 여러 문서를 하나의 행렬로 표현 가능.
인덱스 숫자 하나를 one-hot 벡터로 변환하는 방식. 예를 들어 단어 인덱스가 9라면 9번째 자리만 1이고 나머지는 0인 벡터로 표현. 이렇게 각 숫자를 one-hot 벡터로 바꾸면 문서 하나가 행렬로 표현.
이 방식의 행렬은 대부분 값이 0이고 일부만 1인 희소 행렬이 됨.
## 인덱스 주의사항
인덱스 시작점 차이에 주의 필요. 수학 문서는 주로 1부터 시작하며, 대부분의 범용 프로그래밍 언어는 0부터 시작. Fortran, Julia, MATLAB, Octave 등은 1 기반 인덱스 사용.
문서의 수식과 코드를 함께 볼 때 인덱스 시작점이 0인지 1인지 구분해야 하며, 헷갈리기 쉬운 부분이므로 코딩할 때 주의 필요.
