# 19-넘파이
## 학습 포인트
NumPy의 핵심 객체인 array는 1차원 벡터, 2차원 행렬, 3차원 큐브처럼 차원 확장 가능. 차원 수만큼 인덱스 필요. 배열 생성 시 행 우선 방식으로 값 기록. NumPy array와 matrix의 차이를 3×3의 1로 채운 array와 matrix 곱셈으로 비교.
NumPy array의 축(axis), 인덱싱과 슬라이싱, 전치, 브로드캐스팅을 중점적으로 학습. 특히 새로 생긴 축이 0번 축이 되고 기존 축 번호가 뒤로 밀린다는 점, 그리고 브로드캐스팅에서 차원이 맞춰지는 과정을 정확히 이해하고 사용필요.
## NumPy Array와 Matrix
NumPy array를 만들 때 값은 행 우선 방식으로 기록. 예를 들어 `1, 2, 3, 4`를 지정하면 열 방향으로 먼저 채워지는 것이 아니라 행 방향으로 먼저 채워짐.
모든 원소가 1인 `3 × 3` array와 matrix를 비교. array끼리 `*`로 곱하면 행렬곱이 아니라 같은 위치의 원소끼리 곱하므로 결과도 1들로 구성. 반면 `dot`를 사용하면 행렬곱이 수행되어 각 위치에 3이 나오며, matrix형으로 바꾼 뒤 `*`를 쓰면 행렬곱처럼 동작함.
## Axis
NumPy 다차원 array의 axis는 배열 요소가 늘어선 방향을 의미.
- 1차원 배열은 축이 하나이며 방향성은 없지만 편의상 가로 형태로 표현
- 2차원 배열에서 새 축은 0번 축, 기존 방향은 1번 축으로 이동
- 3차원 배열에서도 새 축은 0번, 기존 축 번호는 하나씩 뒤로 이동
이 축 번호 규칙은 브로드캐스팅을 이해할 때 중요.
## 인덱싱과 슬라이싱
2차원 array에서 특정 범위를 잘라오는 실습. 시작 인덱스와 끝 인덱스를 지정하면 해당 구간이 잘려 나오며, 예시 출력으로 `3, 4, 8, 9, 13, 14`가 확인됨.
마지막 행의 홀수 열만 뽑는 예시에서는 행 인덱스에 `-1`을 사용. Python 리스트처럼 음수 인덱스는 뒤에서부터 세며, `-1`은 마지막 행을 의미. 열 인덱스는 시작을 0으로 두고 끝은 생략해 끝까지 가게 하며, stride를 2로 지정해 하나 건너 하나씩 추출. 그 결과 `45, 47, 49`가 추출됨.
함께 제공된 `NumPy.ipynb` 노트북 파일에서 추가 연습을 직접 해보.
## 전치
행렬에서 전치는 행과 열을 바꾸는 것이며, NumPy에서는 `.T`로 표현. 3차원 배열에서 첫 번째 인덱스에 0을 주고 나머지를 `:`로 두면 0번 축의 첫 번째 장을 뽑아 2차원 행렬을 얻고, 여기에 `.T`를 적용하면 행과 열이 변경.
3차원 이상의 배열은 `transpose` 함수로 축 순서를 바꿀 수 있음. 예시로 `transpose(2, 0, 1)`은 2번 축을 0번으로, 0번 축을 1번으로, 1번 축을 2번으로 보내는 의미. 1~18 값이 들어간 배열을 돌려 보며 첫 번째 장이 `1, 4, 7, 10, 13, 16`, 다음 장이 `2, 5, 8, 11, 14, 17`, 마지막 장이 `3, 6, 9, 12, 15, 18` 형태가 되는 것을 확인.
## Broadcasting
브로드캐스팅은 차원이 다른 배열과 스칼라 또는 배열을 자동으로 맞춰 요소별 연산을 가능하게 하는 기능. 브로드캐스팅을 정확히 이해하지 않고 쓰는 경우가 많으므로 원리를 보고 넘어가야 함.
예시 1:
- `1, 2, 3` 형태의 1차원 array와 스칼라 `2`를 곱셈
- 스칼라는 차원이 없으므로 먼저 1차원으로 확장되고, 크기 3에 맞춰 복제
- 요소별 곱셈 결과는 `2, 4, 6`이 됨
예시 2:
- `4 × 3` 배열과 길이 3인 1차원 배열을 곱셈
- 1차원 배열에 새 축이 왼쪽에 생겨 `1 × 3`처럼 되고, 1인 차원이 4에 맞춰 아래로 확장
- 이후 동일 위치 원소끼리 곱해 결과 생성
예시 3:
- `4 × 1` 배열과 길이 3인 1차원 배열을 곱셈
- 세로 방향 배열은 `4, 1`처럼 2차원으로 생각해야 하며, `4,`만 적으면 옆으로 요소 4개가 있는 1차원 배열이 됨
- 서로 다른 쪽의 1인 차원이 각각 확장되어 `4 × 3` 형태로 맞춰지고, 요소별 곱셈이 수행
새 차원이 기존 차원의 왼쪽에 생성되고, 크기가 1인 차원이 다른 배열 크기에 맞춰 확장되는 broadcasting 구조.
