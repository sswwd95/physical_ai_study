# 15-로지스틱소프트맥스함수미분
## 학습 개요
로지스틱 함수의 미분에 분수함수 미분과 합성함수 미분(체인 룰)을 적용.
## 학습 포인트
- 화면의 로지스틱 함수: `σ(z) = 1 / (1 + exp(-z))`
- 분수함수 미분: `(f'g - fg') / g²`
- `u=-z`로 치환한 뒤 `du/dz=-1`, `d(exp(u))/du=exp(u)`를 곱하는 체인 룰
- 두 음수의 곱으로 `exp(-z)` 항이 양수가 되는 과정
- 로지스틱 시그모이드의 미분 결과는 원래 함수값만으로 `σ(z)(1-σ(z))`처럼 쓸 수 있음
- 소프트맥스는 다입력·다출력 벡터 함수. 각 출력 요소를 각 입력 변수로 편미분해 여러 미분 계수 계산
- 야코비안: 벡터 함수를 벡터 변수로 미분한 결과를 행렬 형태로 구성한 것
## 로지스틱 시그모이드 미분
`exp(-z)`를 미분할 때 `u=-z`로 치환해 체인 룰을 적용. `-z`를 `z`로 미분하면 `-1`이고, `exp(u)`를 `u`로 미분하면 `exp(u)`이므로 결과는 `-exp(-z)`가 됨. 분수 미분 과정에서 앞의 음수와 이 음수가 곱해져 `exp(-z)` 항이 양수로 정리.
이후 식을 정리하면서 `1 + exp(-z)` 꼴을 다시 만들기 위해 앞뒤로 1을 더하고 빼는 조작을 수행. 그 결과 로지스틱 시그모이드의 도함수는 별도 계산 없이 원래 함수값을 사용해 `σ(z)(1-σ(z))`로 구가능.
## 소프트맥스 미분
소프트맥스는 `n`개의 입력을 받아 `n`개의 출력을 만들고, 출력값을 모두 더하면 1이 되는 벡터 함수. 벡터 함수 전체를 한 번에 미분하려고 하면 막막하지만, 각 출력 요소를 하나의 다변수 실함수로 보고 따로 편미분하면 됨.
출력 4개와 입력 4개인 예를 들면, 각 출력마다 입력 4개에 대한 편미분 계수가 생기므로 총 16개의 미분 계수가 생성.
## 소프트맥스 편미분 경우 구분
입력 인덱스 `j`와 출력 인덱스 `i`가 같은 경우:
- 분자는 `exp(z_i)`이고, `i=j`이므로 `z_j`로 미분하면 `exp(z_j)`가 됨
- 분모는 모든 입력의 exponential 합. `z_j`로 편미분 시 `exp(z_j)` 항만 잔존
- 나눗셈 미분 공식을 적용하고 정리하면 `S_j(z)(1-S_j(z))`와 같은 형태가 됨
입력 인덱스 `j`와 출력 인덱스 `i`가 다른 경우:
- 분자 `exp(z_i)`는 `z_j`와 다른 변수이므로 편미분하면 0이 됨
- 분모 미분 항만 남아 음수 형태로 정리
- 결과는 `-S_i(z)S_j(z)` 형태가 됨
## 야코비안
`i=j`인 대각 성분에는 `S_i(1-S_i)` 형태가 오고, `i≠j`인 나머지 성분에는 `-S_iS_j` 형태가 오는 큰 사각형 형태로 미분 계수를 정리. 가로줄은 행, 세로줄은 열이며, 이렇게 함수의 미분 결과가 행렬로 모인 것을 야코비안.
야코비안은 벡터 함수를 벡터 변수로 미분했을 때 나타나는 행렬. 신경망 미분과 역전파에서 활용.
