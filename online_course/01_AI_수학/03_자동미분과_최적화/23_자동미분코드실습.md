# 23-자동미분코드실습
## 학습 포인트
계산 그래프와 체인 룰로 자동 미분을 이해. 예시 `z(x,y)=x×y`, `x=3`, `y=2`에서 `∂z/∂x=y=2`, `∂z/∂y=x=3`이고, 끝에 항등함수 `h=z`를 합성하면 `∂h/∂z=1`. 따라서 `∂h/∂x=2`, `∂h/∂y=3`이 됨. 화면에는 upstream gradient 표기가 확인.
자동 미분은 각 단위 연산의 지역 미분 계수를 구하고, 역전파 방향으로 경로상의 지역 미분 계수와 상류층 미분 계수를 곱해 전체 미분 계수를 계산. 여러 경로가 한 변수로 모이면 각 경로의 기여도를 덧셈.
## 곱하기 함수의 Forward/Backward
먼저 곱하기 함수를 직접 자동 미분하는 코드.
- forward 함수는 `x`, `y`를 받아 곱한 값을 반환
- backward에서 미분 계수를 계산하려면 입력값이 필요하므로 forward 결과와 함께 입력값을 cache에 저장
- 곱하기 함수에서 `x`에 대한 지역 미분 계수는 `y`, `y`에 대한 지역 미분 계수는 `x`다
- backward 함수는 cache에서 저장된 `x`, `y`를 꺼내 위치를 바꾼 미분 계수를 만들고, 여기에 upstream gradient를 곱필요
예시로 `x=2`, `y=3`을 입력했을 때 미분 계수는 각각 `3`, `2`로 계산고 확인.
## 예제 함수 분해
이전 다룬 이변수 함수를 단위 함수로 나누어 직접 자동 미분.
- `A = x*x`
- `B = 2*x`
- `C = A+B`
- `D = log(y)`
- 최종 `F = C*D` 계산
각 단위 함수의 지역 미분 계수:
- 곱하기 함수 `F=C*D`: `∂F/∂C = D`, `∂F/∂D = C`
- 로그 함수 `D=log(y)`: `∂D/∂y = 1/y`
- 더하기 함수 `C=A+B`: `∂C/∂A = 1`, `∂C/∂B = 1`
- `B=2x`: `x`에 대한 미분 계수는 `2`
- `A=x*x`: 두 입력을 서로 다른 입력으로 보면 각 지역 미분 계수는 입력값에 의해 결정. 예시의 `x=1` 위치에서는 각각 1로 계산
## Forward 값과 Backward 값
예시 입력은 `x=1`, `y=2`다.
- `A = 1`
- `B = 2`
- `C = 3`
- `D = log(2) ≈ 0.693`
- `F = C*D ≈ 2.07`
Backward에서는 마지막 곱하기 함수부터 역순으로 진행. `F`를 만들기 위해 사용한 `C`, `D`에 대한 미분 계수를 먼저 구하고, 로그·더하기·곱하기 함수의 backward를 순차적으로 적용. 한 변수로 모이는 여러 경로는 덧셈.
`y`에 대한 편미분은 `∂F/∂D = 3`과 `∂D/∂y = 1/2`를 곱해 `1.5`가 됨. `x`에 대한 편미분은 세 개 경로의 기여도를 곱해 구한 뒤 모두 더함.
## 코드 구조
더하기 함수는 forward에서 두 값을 더해 반환하고 cache를 함께 반환. 지역 미분 계수가 항상 1이므로 backward 함수는 upstream gradient를 그대로 반환.
로그 함수는 NumPy의 로그를 사용해 forward 값을 계산하고, backward에서는 cache에 저장한 `x`로 `1/x`를 계산해 upstream gradient에 곱셈.
전체 함수는 `times`, `add`, `log` 단위 연산을 순서대로 forward 한 뒤, 마지막 연산부터 역순으로 backward 수행. 각 backward 결과를 임시 변수에 담고, 계산 그래프에서 경로가 합쳐지는 지점에서는 그 값을 더해 최종 미분 계수를 도출.
확인된 검증 결과에서 `y`에 대한 미분 계수는 `1.5`로 PyTorch 자동 미분의 정확한 값과 일치. 수치 미분에서는 `1.4989`처럼 약간의 오차가 있었고, 직접 구현한 자동 미분은 `1.5`와 일치함.
