# 21-수치미분
## 학습 개요
컴퓨터 기반 미분 구현 방식인 수치 미분, 심볼릭 연산, 자동 미분 비교와 Python 실습.
## 학습 포인트
- SymPy·Mathematica·Wolfram|Alpha를 이용한 심볼릭 연산
- 직접 미분: 정확하고 빠르지만 복잡한 식은 코드 작성이 어려움
- 수치 미분: 손으로 식을 미분하지 않고 계산
- 자동 미분: 손으로 미분한 것과 같은 결과를 코드에서 얻는 방식
- 실습은 GitHub에서 제공되는 Jupyter Notebook으로 진행
- 전방차분법은 `f(x+h)-f(x)`를 `h`로 나눠 미분 계수를 근사
- 중앙차분법은 `x+h/2`와 `x-h/2`에서의 함수값 차이를 `h`로 나눠 근사하며, 전방차분보다 더 정확
- 수치 미분은 구현이 간단하지만, 변수 수가 많으면 각 변수마다 계산을 반복해야 해서 느리고, 작은 `h`로 나누는 과정에서 수치 오차가 누적가능
## 직접 미분 예제
`(x^2 + 2x) log x` 형태의 함수를 예로 들어 직접 미분. 곱의 미분법을 적용해 앞 함수의 미분 `(2x + 2)`에 `log x`를 곱하고, 뒤 함수의 미분 `1/x`에 앞 함수 `(x^2 + 2x)`를 곱셈. 정리하면 뒤쪽 항은 `x + 2`가 남.
직접 손으로 미분할 수 있으면 이 도함수를 lambda 함수 형태로 코드에 적어 계산하면 됨. 하지만 식이 복잡해지면 직접 미분해 코드로 옮기는 방식이 어려울 수 있음.
## 수치 미분
수치 미분은 매우 작은 구간에 대한 평균 변화율로 미분 계수를 근사. 미분 계수를 처음 배울 때 `0.01` 같은 작은 구간에서 평균 변화율을 구했던 것과 같은 논리.
다만 다변수 함수를 수치 미분할 때는 각 변수마다 작은 구간을 더하고 함수값 차이를 계산해야 하므로 변수 수가 많을수록 속도 저하. 또한 컴퓨터가 숫자를 표현하는 한계 때문에 `h`가 너무 작아지면 오차가 누적될 수 있으므로 `h` 설정이 중요.
## 전방차분과 중앙차분 비교
`x^4` 함수를 특정 위치에서 미분하는 예를 사용.
- `h=0.5`일 때 전방차분법은 현재 점과 앞쪽 점의 평균 변화율을 도출
- 실제 미분 계수는 약 `7.81`인데 전방차분으로는 약 `13.88`이 되어 차이가 큼
- 중앙차분법은 구하고자 하는 점을 기준으로 앞뒤로 `h/2`만큼 떨어진 두 점을 사용
- 중앙차분법의 결과는 약 `8.12`로 실제 값 `7.81`에 훨씬 가까워짐
- `h`를 `0.01`로 줄이면 오차가 거의 없어질 만큼 비슷해짐
## 코드 구조
`numerderiv` 함수 입력: 미분할 함수 `f`, 미분할 점 `x`, 구간 `h`, 방식 `method`. `method`에는 `center` 또는 `forward`를 사용할 수 있고, 각각 중앙차분과 전방차분을 의미.
함수 내부에서는 입력 `x`가 Python의 float 또는 integer 같은 스칼라인지, 벡터 입력인지 판단. 스칼라라면 리스트나 배열처럼 감싸 다변수 함수처럼 처리하여 뒤쪽 코드를 통일. 이후 변수 개수만큼 반복하면서 각 변수에 대해 미분 계수를 계산.
전방차분에서는 원래 값에 `h`를 더한 위치의 함수값을 `grad+`에 담고, 원래 위치의 함수값을 `grad-`에 저장. 중앙차분에서는 `h/2`를 더한 위치와 `h/2`를 뺀 위치의 함수값을 각각 계산. 마지막에 `grad+ - grad-`를 `h`로 나누어 미분 계수를 도출.
## 다변수 함수 수치 미분
후반 학습: `x`, `y` 두 변수를 받는 함수를 정의하고, 기존 예제 함수의 로그 입력을 `y`로 바꿔 일부러 이변수 함수로 생성. `numerderiv`에 이 함수를 넘기고 미분할 포인트로 `x=1`, `y=2`를 넘기면 다변수 함수의 미분 계수가 계산됨.
