# 22-파이토치자동미분
## 학습 포인트
자동 미분은 복잡한 함수를 작은 연산 단위로 나누어 처리하며 핵심은 연쇄 법칙. Forward mode와 reverse mode 중 reverse mode를 다루고, 순전파는 그래프를 왼쪽에서 오른쪽으로 따라가 함수값을 계산하며 역전파는 오른쪽에서 왼쪽으로 미분 계수를 계산. 미분 가능한 복잡한 함수도 빠르게 계산 가능.
PyTorch는 GPU 연산과 자동 미분을 지원하는 Tensor 기반 라이브러리. Tensor에 `requires_grad=True` 설정 후 `backward`, `autograd.grad`를 이용한 미분 계수 계산.
## PyTorch Tensor
PyTorch Tensor는 NumPy array와 같은 다차원 배열이며, 인공지능 분야에서는 Tensor와 배열을 큰 차이 없이 다차원 배열 의미로 사용. NumPy array를 PyTorch Tensor로 바꿀 수 있고, PyTorch Tensor를 다시 NumPy array로 바꿀 수도 있음.
2×3 NumPy array `X` 생성 후 `torch.tensor(X)`로 동일 값을 가진 Tensor 변환. `torch.from_numpy`, `torch.as_tensor` 방식도 사용 가능. 출력 결과는 NumPy array와 구분되는 Tensor 형식.
## requires_grad
PyTorch Tensor 자동 미분 조건: `requires_grad=True`. 기본으로 만든 Tensor의 `requires_grad`는 `False`이고, 이는 해당 변수로 미분할 수 없다는 의미. Tensor 생성 시 `requires_grad=True`를 지정하면 미분 계수를 가질 수 있는 변수로 설정.
## 1변수 함수 자동 미분
이전 수치 미분 사용한 함수 `(x^2 + 2x) log x`를 PyTorch로 계산.
- `torch.tensor(1, requires_grad=True)` 형태로 `x=1` Tensor 변수 생성
- 이 `x`로 함수값 `F`를 계산하는 과정이 forward 과정
- 아직 미분을 하지 않았을 때는 `x.grad`에 아무 값도 없음
- `torch.autograd.backward(F, retain_graph=True)`를 호출하면 계산 그래프를 뒤로 따라가며 `F`를 계산하는 데 입력된 변수 `x`에 대한 미분 계수를 도출
- 실행 후 `x.grad`에는 `3`이 들어감
`retain_graph=True`는 미분 후에도 내부 계산 그래프를 유지하겠다는 옵션이며, 기본값은 `False`.
## autograd.grad
`torch.autograd.grad`는 미분할 변수를 직접 지정하고, 구한 미분 계수를 반환하는 방식. `torch.autograd.grad(F, x)`를 사용하면 `x.grad`에 저장된 값과 같은 `3`이 반환됨.
변수를 튜플로 묶어 여러 개 지정할 수도 있음. 예시에서는 1변수 함수라 의미는 크지 않지만 `(x, x)`처럼 넘기면 같은 미분 계수가 두 개 구해짐.
## 2변수 함수 자동 미분
후반 학습: 수치 미분에서 사용한 것과 같은 2변수 함수를 PyTorch로 자동 미분. `x=1`, `y=2`인 두 Tensor 변수를 만들고 둘 다 미분 가능하도록 설정한 뒤, 두 변수를 받는 함수 `F`를 정의.
`backward`를 수행하면 `F` 계산에 입력된 `x`와 `y`에 대해 한 번에 미분 계수가 구해져 각각 `x.grad`, `y.grad`에 저장. `autograd.grad`를 사용하면 미분할 변수를 직접 지정하고 반환값으로 각 미분 계수를 받을 수 있음.
확인된 결과값은 `2.7726`, `1.5`이며, 이는 PyTorch 자동 미분 값과 NumPy로 직접 미분한 값이 동일하다는 예. 지난 시간의 수치 미분 결과와는 약간의 오차가 있는데, 수치 미분은 근사이고 자동 미분은 연쇄 법칙으로 정확한 미분 결과를 만들기 때문.
