# 30-선형회귀실습
## 학습 포인트
NumPy와 Scikit-learn으로 다항 기저 함수·다항식 특성 실험 결과가 일치함을 확인한 뒤, 라이브러리 내부 선형회귀 알고리즘을 직접 구현. 경사하강법과 정규방정식 두 방식으로 정의된 에러 함수를 최소화하고, L1·L2 규제화가 벡터 norm과 어떻게 연결되는지 확인. 결과는 에러를 최소화하는 다항식 계수.
SciPy `optimize.minimize`를 사용해 다항 회귀의 에러 함수를 직접 최소화. 가설 함수의 차수를 0차, 1차, 3차, 8차로 바꿔 피팅 결과를 비교하며, 차수가 높아질수록 항상 좋은 결과가 되는 것은 아니고 과적합이 생길 수 있음을 확인.
## 에러 함수
선형회귀의 목적은 정의된 에러 함수를 최소화하는 계수 `W`를 찾는 구조. 사용하는 에러 함수는 예측값 `Y`와 정답 `T`의 차이를 제곱해 모두 더하고 앞에 `1/2`를 곱한 형태. 데이터 개수 `N`으로 나누어 평균을 내도 되고, 나누지 않아도 됨.
가설 함수는 다항 기저 함수를 사용해 구성. 1차로 두면 직선이고, 3차나 8차로 두면 더 구불구불한 곡선을 만들 수 있음. 목적 함수는 동일하게 에러 함수이고, 바뀌는 것은 데이터에 맞추려는 가설의 차수.
## 에러 함수 코드 구조
주피터 노트북에는 에러 함수가 코드로 구현되어 있음. 에러 함수는 최적화 대상인 `W`를 입력으로 받고, 에러 계산에 필요한 데이터 `X`, `T`, 그리고 몇 차 다항식을 쓸지 나타내는 `M`을 추가 인자로 입력.
`X_train`은 10개의 값으로 구성된 1차원 벡터. 여기에 0승, 1승,.., `M`승을 적용해 큰 `X` 행렬을 생성. 처음에 이 행렬을 `D × N` 형태로 만들고, `W`는 `reshape(-1, 1)`로 열 벡터 형태로 정렬.
이후 broadcasting으로 각 다항 기저 값에 대응하는 `W`를 곱하고, `axis=0` 방향으로 합해 예측값 `Y` 10개를 생성. 같은 연산은 `X`를 `N × D`로 transpose한 뒤 `W`와 행렬곱하면 한 번에 계산 가능. 이해를 돕기 위해 풀어쓴 방식으로 코딩했지만, 벡터 코딩에 익숙하면 행렬곱 한 줄로 표현 가능.
## Gradient 함수와 최적화
최적화를 하려면 에러 함수를 `W`에 대해 미분한 gradient 함수가 필요. `W`는 다항식 차수에 따라 여러 개의 계수로 구성되므로, 에러 함수는 벡터를 입력받아 스칼라를 출력하는 다변수 스칼라 함수.
SciPy `optimize.minimize`에는 다음을 전달.
- 목적 함수: 에러 함수 `E`
- 시작점: NumPy 랜덤 함수로 초기화한 `W`
- 추가 인자: 다항식 차수 `M`, `X_train`, `t_train`
- gradient 함수: 직접 코딩한 gradient 함수
- method: `BFGS`
BFGS: Conjugate Gradient보다 높은 성능을 기대할 수 있는 최적화 알고리즘.
## 실행 결과와 과적합
0차, 1차, 3차, 8차 기저 함수에 대해 최적화를 수행. 실행은 매우 빠르게 끝나며, 마지막 8차에서는 `successfully` 메시지가 나오지 않았음.
그래프 결과:
- 0차 피팅: 기울기가 없는 상수 함수 형태의 평평한 선
- 1차 피팅: 직선 형태
- 3차 피팅: 원래 곡선을 상당히 잘 따라가는 결과가 나옴
- 8차 피팅: 모든 학습 점을 지나가려 하면서 과도한 굴곡 발생
8차 곡선은 학습 오차를 0에 가깝게 만들기 위해 모든 점을 지나가려 하면서 과도한 굴곡 발생. 원래 패턴과 크게 달라지는 과적합 형태.
계수도 확인하는데, 3차일 때는 0차부터 3차까지 4개의 계수가 결정되고, 8차일 때는 9개의 계수가 결정. 8차의 계수는 만 단위, 10만 단위처럼 매우 크게 결정되며, 이는 점에 억지로 맞추기 위해 `W`가 넓은 범위에서 크게 변한 결과.
