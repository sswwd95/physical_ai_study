# 29-다항기저다항특성
## 학습 포인트
머신러닝 회귀 예제를 위해 sin 함수에 NumPy 랜덤 노이즈를 섞은 데이터를 생성. 원래 곡선(truth)을 찾기 위한 파란색 곡선, 학습에 쓰는 빨간색 점(train data), 적합도를 확인하는 보라색 점(test data)을 구분. Train 데이터가 일반적으로 더 많고 test 데이터는 적음.
동일한 다항 회귀식을 두 관점으로 비교. 하나는 다항식 기저함수를 선형조합해 함수를 만드는 관점이고, 다른 하나는 원래 입력 데이터에 다항 특성을 추가해 선형 회귀 모델에 넣는 관점. NumPy와 scikit-learn은 관점은 다르지만 같은 결과를 낸.
## 학습 메모
수식과 과적합·regularization을 다루며 Christopher Bishop의 *Pattern Recognition and Machine Learning*을 참고했음.
## 데이터와 모델
Christopher Bishop의 *Pattern Recognition and Machine Learning* 예제를 참고한 회귀 데이터 구성. `sin` 함수에 NumPy 랜덤 노이즈를 추가해 학습 데이터 생성.
- 파란색 점선: 찾아야 할 원래 곡선, truth
- 빨간색 점: 학습에 사용하는 train data
- 보라색 점: 학습 후 적합도를 확인하는 test data
일반적으로는 train data가 test data보다 많지만, 이 예제에서는 과적합을 더 극적으로 보이기 위해 test data를 더 많이 둠.
선형 모델은 `w0 + w1 x`처럼 직선으로 데이터를 맞추는 방식. 더 유연한 곡선을 쓰려면 `x^2`, `x^3`처럼 차수를 늘린 다항식을 사용가능. 어떤 막대기 또는 철사를 써서 데이터를 맞출지 결정하는 것이 모델 선택에 해당함.
## 기저함수 관점
기저함수는 원하는 함수를 만들기 위한 재료 함수. 2차식을 만들기 위한 재료 함수로는 상수 함수 `1`, `x`, `x^2`가 있을 수 있고, 각 함수 앞에 계수를 곱해 선형조합하면 하나의 함수를 만들 수 있음.
기저함수는 다항 함수뿐 아니라 `sin`, 지수 함수, 로그 함수 등도 가능하며, 가급적 서로 겹치지 않는 함수를 고르는 것이 좋음. 슬라이드에서는 기저함수를 `φ`로 표시.
다항식 기저를 쓰는 경우 `x^0`, `x^1`, `x^2`,.., `x^m`까지의 기저를 선택하고, 그 앞의 계수들을 학습해 데이터에 맞는 함수를 탐색. 결정 항목은 다항식 기저의 차수와 각 기저에 적용할 계수.
## 다항 특성 관점
같은 식을 입력 데이터에 새로운 특성을 추가하는 관점으로도 볼 수 있음. 예를 들어 `x`가 집의 너비라면 `x^2`는 면적, `x^3`는 부피처럼 해석가능. 물론 `x^4`, `x^5`부터는 물리적 의미가 명확하지 않을 수 있지만, 이런 변환된 특성들을 조합해 함수를 만들 수 있음.
식의 형태는 기저함수 관점과 같지만, scikit-learn은 이 문제를 PolynomialFeature를 데이터에 부여한 뒤 LinearRegression으로 학습하는 방식으로 바라봄.
## 벡터 표현
기저함수와 계수는 벡터로 표현 가능. 계수 벡터 `w`를 행 벡터로 두고, 기저함수들을 모은 `φ(x)`를 열 벡터로 두면, 둘의 곱으로 출력값을 계산 가능. `φ(x)`는 숫자 하나 `x`를 받아 `m+1`개의 값을 내는 1변수 벡터 함수이며, `R`에서 `R^(m+1)` 공간으로 매핑함.
임의의 계수 벡터를 정하면 곡선이 만들어지지만, 데이터와 차이가 클 수 있음. 그래서 라이브러리를 사용해 계수를 데이터에 맞게 피팅.
## NumPy와 Scikit-Learn 비교
NumPy에서는 입력 `X`와 타깃 `T`를 넘기고 1차 또는 `m`차로 피팅하도록 지정하면 다항식 피팅이 수행.
scikit-learn에서는 먼저 `LinearRegression` 모델을 만들면 1차 직선으로 피팅. 다항식 모델을 쓰려면 `PolynomialFeature`를 만들고 `LinearRegression`과 `make_pipeline`으로 연결해 학습. 이는 데이터에 다항 특성을 추가한 뒤 선형 회귀를 적용하는 관점.
두 라이브러리로 같은 데이터셋을 풀면 결과가 완전히 동일하고, 결정된 `w` 계수도 동일. `linreg.ipynb`에서 데이터를 로딩한 뒤 NumPy로 1차와 4차 피팅을 하고, scikit-learn에서는 `LinearRegression`과 `PolynomialFeature + LinearRegression` pipeline을 실행해 같은 결과를 확인.
