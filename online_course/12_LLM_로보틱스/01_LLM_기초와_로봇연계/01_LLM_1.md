# LLM 1
## 학습 내용
### ROS와 LLM 결합
- ROS와 LLM을 결합해 자연어를 이해하고 행동하는 로봇 실습
- Gemini와 ROS 연동 실습
- LLM과 ROS 연동 중심 구성
### 기존 프로그램과 LLM의 차이
- 기존 프로그램은 정해진 입력에 대해 정해진 출력을 내는 구조
- LLM은 정해지지 않은 입력에 대해 정해지지 않은 출력을 내며, 같은 질문에도 다른 답을 가능
- 사람이 감각적으로 거리를 판단하는 것과 달리 컴퓨터는 거리를 정량적으로 계산
- ROS2 노드와 Service를 통한 명령 전달 구조로 연결
