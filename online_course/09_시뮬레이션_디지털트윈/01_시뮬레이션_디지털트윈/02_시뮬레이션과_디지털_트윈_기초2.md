# 시뮬레이션과 디지털 트윈 기초 2
## 학습 내용
### 시뮬레이터 선택과 환경 제약
- 모든 시뮬레이터가 Gazebo보다 설치가 쉬운 것은 아니며, Docker 환경에서는 설치·연동에 제약이 있음
- 두산로보틱스가 협동로봇 디지털 트윈용 시뮬레이터 소스 코드를 GitHub로 배포하지만, Docker 환경에서는 활용이 제한됨
- 실습 환경에서도 버전 업데이트 후 설치가 꼬여 실습 시연이 어려움
### MuJoCo·Gazebo·Isaac Sim
- Windows에서도 실행되는 MuJoCo를 실습에 사용할 예정
- Gazebo는 ROS 기반 시뮬레이터
- Isaac Sim은 GPU가 필요해 실습 환경에서 실행하기 어려움
- MuJoCo는 Windows에서 실행되며, 다른 T1 실습에 사용할 예정
- MuJoCo와 ROS를 연동하는 것 자체도 별도의 프로젝트가 가능
